# plan/ideas — 구상 단계 아카이브

아직 확정되지 않은, 무르익는 중인 아이디어를 모아두는 곳.

## 이 폴더의 성격

- **여기 있는 문서는 "확정된 스펙이 아니다".** 방향을 굳히기 위한 사고의 흔적이다.
- spec/strategic과 섞지 않는 이유: `spec/`은 "확정된 것"의 신뢰를 지켜야 하고, `strategic(highlevel)/`은 전략·PRD 수준까지 정리된 것을 담는다. 구상은 그 이전 단계다.

## 승격 흐름

```
ideas/  →  무르익으면  →  strategic(highlevel)/ (PRD·정책서)  →  확정되면  →  spec/
```

아이디어가 정리 단계로 올라가면 이 폴더에서 빼고 상위 계층으로 옮긴다.

## 현재 문서

- `Insight_Archive_구상.md` — 마케터의 감(가설)을 데이터로 검증해 아카이브하는 콘텐츠 허브 구상
- `AI_Workflow_Studio_정책서_v0.1.md` — 노드·MCP 기반 워크플로우를 플랫폼에 얹는 구상 (정책서 형식이나 아직 구상 단계)
