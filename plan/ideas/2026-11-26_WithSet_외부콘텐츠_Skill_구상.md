## 1. WithSet 구조 매핑

```
Library(분석 리포트) → Chat("이 분석으로 카드뉴스 만들어줘") → SpinX → Skill(외부 콘텐츠 작성 방식) → Artifact(원고 · 이미지 · 캡션)
```

| 구성 | 이 기능에서의 역할 |
|---|---|
| Library | 원료. 분석 리포트의 발견 · 수치 · 조건(업종 · 기간 · 매체) |
| Skill | 채널별 작성 방식. 구성 순서, 톤, 검증 규칙, 디자인 템플릿 |
| Tools | 외부 통계 원문 확인(공공기관 보도자료 등). Phase 3 이후 |
| Artifacts | 결과물. 생성 위치 · 사용 Skill · 근거 분석과 함께 보관 |

## 2. 산출물 유형 (파일럿 기준)

| 유형 | 채널 | 형태 | 톤 |
|---|---|---|---|
| 기고문 | 협회지 · 업계 매거진 | 원고(docx) + 도표 PNG + 게재 예시(PDF) | 한다체, 데이터 중심, 홍보 배제 |
| 카드뉴스 | 인스타그램 등 SNS | 4:5 카드 9장 + 캡션 | 해요체, 통념 → 반전 → 제안 구조, 저장 유도 |
| (확장) 광고주 설명 자료 | 제안 · 보고 | 추진계획 A3 예시와 동일 | 근거 인용 중심 |

- 카드뉴스는 두 가지 톤으로 시안 제작: 다크(공항 전광판 모티프) / ReadySet 라이트(무채색 + 시그니처 민트는 '정답'에만)

## 3. Skill에 담을 검증 규칙 (파일럿에서 확정한 것)

| 규칙 | 내용 |
|---|---|
| 숫자 1:1 대조 | 결과물의 모든 숫자는 Library 원본 수치와 대조. 반올림 · 단위 변환은 표기 규칙으로 고정 |
| 주장 범위 제한 | 비유 · 카피는 분석이 말하는 범위 안에서만. 예) 전체 CTR 상승을 "떠난 사람들이 광고를 봤다"로 쓰지 않음 |
| 외부 통계 원문 확인 | 언론 보도 수치는 기관 원문으로 재확인 후 사용. 집계 기준(예: 환승객 포함)까지 각주에 표기 |
| 상대 시점 배제 | "올해 · 지난해" 대신 연도 표기. 배포 · 열람 시점이 바뀌어도 유효하게 |
| 채널별 홍보 수위 | 협회지 기고는 자사 솔루션 홍보 배제(데이터 출처 표기로만 노출), 자사 채널은 허용 |
| 용어 일관성 | 시맨틱 레이어(K1) 기준 용어 사용. 예) 평시, 장기 · 단기 연휴, 놓친 기회 |
| 방법론 배치 | 분석 방법은 본문 앞이 아닌 각주로. 독자 피로도 관리 |

## 4. 정책 검토 사항

- **공개 범위**: 외부 공개물이므로 audienceLevel '공개' 등급 콘텐츠만 원료로 사용. 매체 프로모션 등 임직원 전용 정보는 검색 대상에서 사전 제외 (추진계획 6. 정책과 동일 원칙)
- **채널 분리**: 추진계획의 "플랫폼에는 분석 내용만, 뉴스레터 캐릭터 · 레이아웃은 메일 채널에서만" 원칙과의 관계 정리 필요. 외부 콘텐츠 템플릿을 플랫폼 기능으로 둘지, Skill 단위 자산으로만 둘지
- **검수 · 승인**: 생성 후 사람 검수와 승인 단계 필수. K9(근거 없으면 답하지 않기, 트레이스 기록)와 연결해 사용 근거 · 검증 결과를 Artifact에 함께 기록
- **브랜드 표기**: 데이터 출처(CJ메조미디어 집행 데이터)와 플랫폼 로고(ReadySet) 노출 기준을 채널별로 정의

## 5. 단계

| Phase | 범위 |
|---|---|
| 1 | 해당 없음. Library에 분석이 구조화되어 쌓이는 것이 전제 |
| 2 | Skill(기고문 · 카드뉴스 작성 방식) + Artifact 보관. 템플릿은 ReadySet 톤앤매너 기준 1종부터 |
| 3 | Tools로 외부 통계 원문 자동 확인 |

## 6. 열린 질문

- 외부 콘텐츠 생성을 운영자(Marketer) 전용으로 둘지, 외부 사용자(대행사 · 광고주)에게도 열지
- 디자인 템플릿을 고정할지, 브랜드별(광고주 채널)로 바꿀 수 있게 할지
- 결과물이 외부에 게재된 뒤 반응(조회 · 저장)을 다시 Library에 연결할지
