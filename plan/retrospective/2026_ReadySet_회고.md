# 2026 ReadySet 회고 — 거버넌스를 세운 해

> 상태: 초안. 성공지표의 수치는 데이터 확보 후 채운다(현재 자리만 마련).
> 목적: 팀 요청에 따른 2026 상황 회고. 이후 보고 자료로도 활용.
> 한 줄: 2026은 개별 기능을 늘린 해가 아니라, **흩어진 광고 도구를 하나의 원칙·구조·언어로 묶는 "ReadySet 거버넌스"를 세운 해**다.

---

## 0. 이 문서의 성격

- 무엇을 만들었는가(사실)를 먼저 담고, 그것이 만든 효과(수치)는 데이터 확보 후 채운다.
- 지어낸 성과·수치는 넣지 않는다. 아직 측정 안 된 것은 "측정 대상"으로 남긴다.
- 팀 로드맵(2025 기반 → 2026 가시화·지원 → 2027 외부 진출) 중 **2026 구간**을 돌아본다.

---

## 1. 2026 한 줄 정의 — "거버넌스를 세웠다"

2026의 성과는 솔루션 개수가 아니다. **ReadySet이라는 거버넌스**다.

렙사의 광고 도구는 원래 목적별로 흩어져 있었다(조회·리포팅·최적화·자동입찰 등이 각자). ReadySet은 이걸 대체·통합하려는 게 아니라, **예측·분석 영역에 하나의 판단 기준과 구조를 세운** 것이다. 개별 기능을 쓰던 상태에서 "하나의 전략 세션 안에서 판단한다"는 틀로 옮긴 것 — 이게 거버넌스다.

> War Room 철학의 문장 그대로다: "우리는 흩어진 광고 도구의 집합이 아니라, 미디어 전략을 다루는 하나의 상황실이다."

---

## 2. 우리가 세운 거버넌스의 네 층

거버넌스는 눈에 보이는 화면만이 아니다. 아래 네 층을 함께 세운 것이 2026의 실체다.

### 2-1. 제품 철학 거버넌스 — 판단의 기준

- **War Room 철학** 정립: 복잡함의 추상화 / 하나의 전략 세션 / SpinX 큐레이션 / 모델에 대한 존중.
- **UI 디자인 원칙** 정립: 고밀도·저소음, 시그니처 그린 = "시스템이 내린 판단", "있어 보임 = 근거 + 크래프트맨십".
- 의미: 새 화면·기능을 만들 때 매번 처음부터 논쟁하지 않는다. **판단 기준이 문서로 선다.**

### 2-2. 구조 거버넌스 — 공통 뼈대(IA)

- **4계층 IA** 확립: SlotBoard → Slot → 솔루션 → 시나리오.
- **4솔루션을 하나의 흐름**으로: DataShot → Ad Curator → Budget Optimizer → Reach Caster.
- **공통 패턴** 표준화: 3단계 생성 위자드, Configuration Summary, Breadcrumb 정책, 공통 컴포넌트.
- 의미: 솔루션이 늘어도 사용자는 **같은 사용법**으로 쓴다. 학습 비용이 솔루션마다 리셋되지 않는다.

### 2-3. 데이터·용어 거버넌스 — 공통 언어

- **업종 분류·매체/상품 API 매핑** 자산화 (Google/Meta/Kakao/Naver 매핑).
- **SpinX MCP 심사·승인 정책** 수립: 외부 도구를 AI에 붙일 때의 등록→심사→승인→활성화 원칙.
- 의미: 솔루션 간·매체 간 용어가 제각각이지 않도록 **하나의 기준 언어**를 갖췄다.

### 2-4. 경험 거버넌스 — 세션의 연속성

- **맥락 승계**: Budget Optimizer 결과 → Reach Caster Easy Create로 업종·예산·기간·KPI 프리필.
- **SpinX 통합**: 결과 화면마다 AI 챗을 얹어 수치를 서사로 해석.
- 의미: 도구를 옮겨다녀도 **생각의 흐름이 끊기지 않는다.**

---

## 3. 무엇을 했나 — 전략 4줄 요약표

> "수치로 확인된 효과" 열은 데이터 확보 후 채운다(§5 참조). 지금은 사실과 의도만.

| 전략 | 무엇을 했나 | 노린 사용자 경험 | 수치로 확인된 효과 |
|---|---|---|---|
| **① 하나의 War Room** | 예측·분석 영역을 SlotBoard 하나로 통합, 4솔루션을 한 전략 세션으로 묶음 | 도구를 옮겨다니지 않고 한 자리에서 캠페인 전략 판단 | *(측정 대상 — §5 ①)* |
| **② 맥락 승계** | BO 결과 → RC Easy Create, 업종·예산·기간·KPI 프리필 | 다음 단계에서 다시 입력하지 않음, 세션이 끊기지 않음 | *(측정 대상 — §5 ②)* |
| **③ 즉시 활용형 벤치마크** | DataShot을 업종 벤치마크 기반으로, 광고주 데이터 없이 업종 선택만으로 분석 | 데이터 수집·학습 대기 없이 바로 시작 | *(측정 대상 — §5 ③)* |
| **④ SpinX 통합** | 결과 화면마다 SpinX 챗을 얹어 수치를 업종 맥락의 서사로 해석 | 별도 AI 도구 학습 없이 결과 화면에서 바로 해석 | *(측정 대상 — §5 ④)* |

## 4. 구축한 솔루션 현황 (사실)

| 솔루션 | 상태 | 핵심 |
|---|---|---|
| **DataShot** | 구현 완료 | 업종 벤치마크 데이터셋 생성·조회 (3단계 위자드) |
| **Reach Caster** | 구현 완료 | 크로스미디어 통합 도달 예측 (Ratio Finder / Reach Predictor), 시나리오 비교 |
| **Budget Optimizer** | 구현 (Meridian 기반) | KPI 목표 기반 미디어믹스 예산 최적화, Easy Create로 RC 연계 |
| **Ad Curator** | 준비 중 | 캠페인 성과 기반 맞춤 상품 큐레이션 |
| **SpinX** | 구현 완료 | 결과 해석 AI 챗, MCP 사용 정책 수립 |

> 상세 구조는 `plan/strategic(highlevel)/예측분석_플랫폼_IA_v1.0.md` 기준.

## 5. 성공지표 — 채워야 할 데이터 (문의 목록)

아래는 §3 표의 "수치로 확인된 효과"를 정직하게 채우기 위해 필요한 데이터다. 확보되는 대로 표에 반영한다. **없는 항목은 "2027 측정 지표"로 이월**한다.

### 규모·활동 (거버넌스가 실제로 돌아가는가)
- [ ] 생성된 Slot 수 / 광고주 수
- [ ] 누적 시나리오·데이터셋 생성 수
- [ ] ReadySet 활성 사용자 수 (렙사 내 팀·인원), 도입 부서 수

### ① 하나의 War Room
- [ ] (before) 통합 전 캠페인 하나에 쓰던 도구 개수 / 화면 이동 횟수
- [ ] (after) SlotBoard에서 처리하는 비율

### ② 맥락 승계
- [ ] BO → RC Easy Create 사용 건수 / 전환율 (BO 완료 중 RC로 이어진 비율)
- [ ] Easy Create 프리필로 아낀 재입력 항목 수

### ③ 즉시 활용형 벤치마크
- [ ] DataShot 데이터셋 생성 건수 / 실사용 업종 수 (22개 중)
- [ ] 데이터 준비 → 첫 분석까지 소요 시간 (VIPer의 학습 대기 대비 우위 증빙)

### ④ SpinX 통합
- [ ] SpinX 질의 수 / 활성 사용률 (결과 조회 중 SpinX 사용 비율)
- [ ] 재질의율 / 세션당 평균 질의 수

> 우선순위: **규모 숫자 + ② Easy Create 전환**이 임팩트가 가장 크다. 이 둘만 있어도 "거버넌스를 세웠고 실제로 돌아간다"가 증명된다.

---

## 6. 2026 → 2027 다리

2026이 "거버넌스를 세운 해"라면, 2027은 그 거버넌스 위에서 **루프를 하나 더 돌리는 해**다.

- 지금 ReadySet은 **캠페인 시작 전 예측**에서 끝난다.
- 2027엔 집행 실측을 매체 MCP로 받아 예측과 대조하는 **검증 루틴(Performance Tracker)**이 붙어, 예측 → 실측 → 교정이 맞물려 도는 닫힌 루프가 된다.
- 상세: `plan/ideas/2027_ReadySet_Product_Direction_구상.md`
