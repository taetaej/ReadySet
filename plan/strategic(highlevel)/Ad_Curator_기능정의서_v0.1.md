# 2. 기능 정의 분류 기준

**우선순위**

| 우선순위 | 기준 |
|---|---|
| P0 | 목표 달성을 위해 반드시 필요한 기능 |
| P1 | 중요하지만 대안 또는 단계적 적용이 가능한 기능 |
| P2 | 없어도 핵심 목표 달성에 영향이 적은 개선 기능 |

**개발 검토 결과**

| 판정 | 기준 |
|---|---|
| 가능 | 현재 확인된 구조와 기술로 구현 가능하며 별도 선행조건이 없음 |
| 조건부 가능 | 특정 정책·기술·일정·외부 의존성 등의 조건이 충족되면 구현 가능 |
| 불가 | 현재 제약 안에서 구현할 수 없거나 요구사항의 핵심 목적을 달성할 수 없음 |
