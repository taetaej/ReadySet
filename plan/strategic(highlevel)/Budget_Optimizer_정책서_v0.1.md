# 1. Budget Optimizer 정의

## 1.1 솔루션 개요

Budget Optimizer는 사용자가 설정한 KPI 목표에 따라 선택된 매체/광고상품 간 **최적 예산 배분안**을 도출하는 솔루션이다.

- 22개 업종별 Meridian(Media Mix Model) 기반 예측 모델 보유
- 외생변수(Meridian 기본 기능) 적용으로 시장 환경 반영
- KPI 최적화 목적함수에 따라 배분 결과 산출

## 1.2 AS-IS → TO-BE

| 구분 | AS-IS (MTS) | TO-BE (ReadySet) |
|---|---|---|
| 플랫폼 | 사내 기간계(MTS) | ReadySet 예측/분석 플랫폼 |
| 모델 | Meridian (외생변수 미적용) | Meridian + 외생변수 적용 (고도화) |
| KPI | 노출, 클릭, 조회, 도달 | 동일 (확장 가능) |
| 매체 | - | Google, Meta, Naver GFA, Kakao (4개 매체) |
| 예산 고정 | 미제공 | 특정 매체/상품 예산 고정 후 잔여 최적화 |
| 시각화 | 2종 | 보강 예정 (상세 기획 시 확정) |
| AI 인사이트 | 미제공 | SpinX 기반 결과 해석 텍스트 생성 |
| Reach Caster 연계 | 미제공 | 결과 → Reach Predictor 자동 매핑 |
| 외부 사용자 접근 | 불가 | 광고주/에이전시 직접 결과 조회 가능 |

# 2. 모델 정책

## 2.1 모델 구조

| 항목 | 정의 |
|---|---|
| 모델 기반 | Google Meridian (Bayesian MMM) |
| 업종 수 | 22개 업종별 개별 모델 |
| 외생변수 | Meridian 기본 기능 활용 (시장 환경, 계절성 등) |
| 최적화 목적함수 | 사용자 선택 KPI에 따라 결정 |
| 학습 데이터 | BRIDGE 원천 데이터 기반 |

## 2.2 업종 매핑

- 시나리오 생성 시 사용자가 선택한 브랜드로부터 업종 자동 식별
- 식별된 업종에 해당하는 Meridian 모델이 분석에 사용됨
- 업종 목록: 🚩 DS팀 확정 후 업데이트 (기존 22개 업종 기준 유지)

## 2.3 모델 업데이트 주기

| 항목 | 정책 |
|---|---|
| 정기 업데이트 | 월 1회 (BRIDGE 원천 데이터 갱신 시) |
| 모델 버전 관리 | 업데이트 시 이전 버전 보관, 기존 시나리오 결과는 생성 시점 모델 버전 기준 유지 |
| 외생변수 갱신 | 모델 업데이트와 동기화 |

## 2.4 KPI별 최적화 정의

| KPI | 최적화 목적 | 설명 |
|---|---|---|
| 노출 (Impression) | 노출 수 최대화 | 총 예산 내 노출 극대화 배분 |
| 클릭 (Click) | 클릭 수 최대화 | 총 예산 내 클릭 극대화 배분 |
| 조회 (View) | 조회 수 최대화 | 총 예산 내 영상 조회 극대화 배분 |
| 도달 (Reach) | 도달률 최대화 | 총 예산 내 도달 극대화 배분 |

- KPI는 시나리오당 **1개만** 선택 가능
- 선택된 KPI에 따라 모델의 목적함수가 결정됨

## 3.3 예산 고정(Fix) 정책

### 3.3.1 정의

사용자가 특정 매체/광고상품에 예산을 **고정 지정**하면, 해당 금액은 최적화 대상에서 제외되고 나머지 잔여 예산만 최적화 대상으로 배분된다.

### 3.3.2 규칙

| 규칙 | 설명 |
|---|---|
| 고정 대상 | 선택된 매체/광고상품 중 일부에 대해 예산 금액 직접 지정 |
| 잔여 예산 계산 | 잔여 예산 = 총 예산 - 고정 예산 합계 |
| 최적화 범위 | 고정되지 않은 매체/상품에 대해서만 잔여 예산 최적 배분 수행 |
| 유효성 검증 | 고정 예산 합계 ≥ 총 예산인 경우 에러 처리 (최적화 대상 예산이 0 이하) |
| 복수 고정 | 여러 매체/상품에 동시 고정 가능 |
| 전체 고정 불가 | 최소 2개 이상의 매체/상품이 최적화 대상으로 남아야 함 |

### 3.3.3 UI 동작

1. 매체/광고상품 선택 후, 각 항목에 "예산 고정" 토글 또는 입력 필드 제공
2. 고정 설정 시 해당 항목은 최적화 대상에서 제외됨을 시각적으로 표시
3. 잔여 예산 실시간 계산 표시

# 4. Reach Caster 연계 정책

## 4.1 연결 구조

```
Budget Optimizer 시나리오 (완료 상태)
    ↓ "Reach Caster로 분석하기" CTA
Reach Caster > Reach Predictor 시나리오 생성 화면
    → 매체별 배분 예산 자동 프리필
```

## 4.2 연결 규칙

| 규칙 | 설명 |
|---|---|
| 연결 조건 | Budget Optimizer 시나리오 상태가 `완료(Completed)`인 경우에만 활성화 |
| 동일 Slot 원칙 | 연결된 Reach Caster 시나리오는 동일 Slot 내에 생성됨 |
| 데이터 매핑 | Budget Optimizer 결과의 매체별 배분 예산 → Reach Predictor의 매체별 예산 입력에 자동 매핑 |
| 매핑 가능 조건 | Budget Optimizer에서 선택한 매체/상품이 Reach Predictor에서 지원하는 매체/상품과 일치하는 경우에만 매핑 |
| 매핑 불일치 처리 | 일치하지 않는 매체/상품은 매핑에서 제외, 사용자에게 안내 메시지 제공 |
| 수정 가능 | 프리필된 값은 사용자가 수정 가능 |
| 연결 이력 | 연결 생성 시 원본 Budget Optimizer 시나리오 ID를 Reach Caster 시나리오 메타데이터에 기록 |

## 4.3 연결 해제

- Reach Caster 시나리오는 독립적으로 존재하므로, 원본 Budget Optimizer 시나리오가 삭제되어도 Reach Caster 시나리오는 유지됨
- 연결 메타데이터만 참조 불가 상태로 변경

# 5. SpinX for Budget Optimizer

## 5.1 서비스 레벨

| 서비스 레벨 | 설명 |
|---|---|
| 시나리오 상세 결과 뷰 | 단일 시나리오 결과에 대한 질의응답 |
| 시나리오 비교 뷰 | 선택된 복수 시나리오 결과에 대한 질의응답 |

## 5.2 인터페이스 및 사용 방식

- **플로팅 인터페이스**: 각 상세 결과 화면 우측 하단의 플로팅 액션 버튼을 통해 서비스를 호출함
- **채팅 기반 UI**: 버튼 클릭 시 전용 채팅 UI가 확장되며, 사용자는 자연어 기반의 질의응답을 통해 인사이트를 획득함

## 5.3 분석 및 응답 원칙

### 데이터 근거 답변

서비스 레벨에 따라 제한된 데이터를 참조하여 답변함

| 서비스 레벨 | 참조 데이터 |
|---|---|
| 시나리오 상세 결과 뷰 | 해당 시나리오 결과 데이터 |
| 시나리오 비교 뷰 | 선택한 시나리오 결과 데이터 |

- **근거 자료 제시**: 답변 도출에 활용된 관련 수치 및 계산 근거를 함께 제시하여 정보의 신뢰성을 확보함. Web Search 결과, RAG Search 결과는 출처 표시 UI 제공
- **자연어 확장**: 사용자는 자연어 질문을 던져 심층적인 분석을 이어갈 수 있음

## 5.4 인사이트 내용 방향

- 최적 배분 결과 요약
- KPI 관점에서 가장 효율적인 매체/상품 하이라이트
- 예산 고정이 적용된 경우, 고정 vs 최적화 결과 비교 코멘트
- 🚩 상세 프롬프트 및 출력 형식은 상세 기획 시 DS/SpinX팀 협의

## 5.5 사용량 정책

- 사용량은 플랫폼 단위로 관리됨 (Budget Optimizer 단독 정책 아님)
- 사용자당 월 100건 대화 전송 제한
- 상세 정책은 플랫폼 공통 정책 참조

# 핵심 용어 정의

| 용어 | 정의 |
|---|---|
| Budget Optimizer | KPI 기반 매체 예산 최적 배분 솔루션 |
| Meridian | Google 개발 Bayesian Media Mix Model 프레임워크 |
| 외생변수 | 모델 외부에서 영향을 미치는 환경 변수 (계절성, 시장 트렌드 등) |
| 예산 고정(Fix) | 특정 매체/상품에 예산을 직접 지정하여 최적화 대상에서 제외하는 기능 |
| KPI 목적함수 | 선택된 KPI를 극대화하기 위한 최적화 기준 함수 |
| Slot | ReadySet 플랫폼 내 광고주 기반 시나리오 관리 단위 |
| BRIDGE | CJ 메조미디어 광고 데이터 수집 시스템 |
| SpinX | ReadySet 플랫폼 AI 기반 결과 해석 에이전트 |
