# Executive Summary — Phase 2: Budget Optimizer 고도화

## 1. 추진 배경 및 필요성

- 2026년 7월 ReadySet 플랫폼 오픈 이후 외부(광고주/에이전시)로부터 긍정적 반응 확인 → 솔루션 라인업 확장 시급
- 기존 Budget Optimizer는 사내 기간계(MTS)에 종속되어 기능적 한계 존재
- 경쟁사(나스미디어 VIPer, ADOASIS 등)가 Meridian/Robyn 기반 MMM을 제공하는 시장 환경에서 모델 경쟁력 확보 필요

## 2. 핵심 고도화 전략

| 축 | 전략 | 내용 |
|---|---|---|
| Model | Meridian 모델 고도화 + 외생변수 | 외생변수 적용, 모델 정확도 개선으로 품질 강화 (22개 업종) |
| Function | 실무 유즈케이스 기능 | 예산 고정(Fix), 시각화 고도화, Reach Caster 연결 |
| Intelligence | SpinX 적용 | AI 기반 결과 해석 인사이트 자동 생성 |
| Platform | ReadySet 이관 | 외부 사용자 직접 접근, Slot Home/Board 연동, 플랫폼 알림 |

## 3. 기대효과 (Business Impact)

- **비딩 경쟁력**: 고도화된 모델 + 최적화된 프로덕트로 즉시 제안 활용 가능, 데이터 부족 광고주도 업종 모델로 커버
- **업무 효율화**: 엑셀 재가공/수작업 리포트 제거, 플랫폼 내 생성→확인→공유 원스톱 완결
- **의사결정 지원**: SpinX 인사이트로 비전문가도 결과 즉시 이해, 셀프 서비스형 해석 제공
- **End-to-End 플래닝**: Budget Optimizer → Reach Caster 연결로 "예산 배분 → 도달 예측" 단일 플로우 실현
- **플랫폼 가치**: ReadySet 3번째 솔루션 안착, 통합 예측/분석 플랫폼 포지션 전환 가속

## 4. 실행 계획 (Implementation Plan)

- **일정**: 2026.08 ~ 2026.11.05 (약 10주, MVP 기준)
- **인력**: PM/PO 1명, DS 1명, B/E 2명, F/E 1명, QA 전원 참여

# 1. 배경 (Background)

## 1.1 현황 (Current State)

- Budget Optimizer는 기존 사내 기간계 플랫폼(MTS)에서 운영되어 왔으며, KPI 기반 매체 예산 최적화 솔루션으로 활용됨
- 기존 MTS 내 Budget Optimizer는 Meridian 기반으로 동작하며, 22개 업종별 모델을 보유
- ReadySet 플랫폼으로의 이관 및 모델 고도화를 통해 솔루션 경쟁력 강화 필요

# 2. 목적 (Purpose)

기존 기간계 시스템 종속에서 벗어나 고도화된 예측 모델과 실무 유즈케이스 기반 기능과 AI Agent를 적용한 솔루션으로 진화하는 것을 목적으로 함

- **솔루션 독립 및 자산화**: MTS 의존도를 탈피하여 ReadySet 플랫폼 내 독자적 아키텍처를 확보함으로써, 변화하는 마케팅 환경에 유연하게 대응
- **예측 모델 고도화**: 외생변수 적용 및 모델 튜닝으로 예측 정확도와 모델 경쟁력 강화
- **지능형 의사결정 체계로의 전환**: SpinX와 실무 유즈케이스 기반 기능(예산 고정, 시각화 고도화)을 통해 즉시 전략 수립에 활용할 수 있는 분석 환경 구축

# 6. UIUX

## 6.1 시나리오 생성 플로우 개선

- **Guided Input**: 브랜드 → 업종 자동 매핑, KPI 선택 → 매체/상품 → 예산 순으로 단계별 가이드형 입력 구성
- **예산 고정 인터랙션**: 매체/상품별 예산 고정 토글 + 잔여 예산 실시간 계산 표시로 직관적 조작

## 6.2 결과 화면 시각화 고도화

- **결과 대시보드**: 테이블 + 차트가 한 화면에서 병렬 제공, 핵심 지표 하이라이트
- **Interactive Chart**: 기여도, 효율, 반응 커브 등 한눈에 인사이트를 파악할 수 있는 차트 제공
- **SpinX 인사이트 영역**: 결과 화면 내 AI 해석 텍스트 전용 섹션 배치

## 6.3 SpinX for Budget Optimizer

- **Contextual Insight**: 결과 데이터(배분 비율, KPI 예측값, 효율 지표)를 기반으로 맥락에 맞는 해석 텍스트 자동 생성
- **핵심 매체 하이라이트**: KPI 관점에서 가장 효율적인 매체/상품을 자동 식별하여 강조

## 6.4 플랫폼 표준 UX 적용

- 시나리오 상태 표시, Final Set 뱃지 등은 기존 플랫폼(ReadySet <> Reach Caster) 패턴을 준수하여 일관된 UX 제공

## 6.5 Reach Caster 연결 인터페이스

- **CTA 배치**: 결과 화면 내 "Reach Caster로 분석하기" 버튼, 연결 가능 조건(완료 상태) 충족 시 활성화
- **매핑 프리뷰**: 연결 시 어떤 값이 Reach Predictor에 프리필되는지 사전 확인 가능

# 7. 포지셔닝 (Positioning)

## 7.1 시장 내 차별점

| 경쟁 구도 | 일반 MMM 솔루션 (ADOASIS, 나스미디어 VIPer) | CJ 메조미디어 Budget Optimizer |
|---|---|---|
| 데이터 기반 | 특정 브랜드(광고주) 자사 데이터 | 22개 업종 데이터 기반 특화 모델 (업종 벤치마크) |
| 도입 속도 | 수개월 데이터 수집 → 모델 학습 필요 | 즉시 활용 가능 (업종 선택만으로 분석 시작) |
| 비용 | 고비용 컨설팅 모델 | 플랫폼 서비스형 제공 |
| 연계 분석 | 예산 배분 단독 | 예산 배분 → 도달 예측(Reach Caster) 연속성 제공 |

## 7.2 포지셔닝 메시지

> **"업종 인텔리전스 기반 즉시 활용형 예산 최적화"**

- 렙사(미디어 렙)로서 축적한 업종별 광고 집행 데이터와 시장 패턴을 모델에 내재화
- 광고주 자체 데이터 수집/학습 대기 없이, 브랜드가 속한 업종 선택만으로 최적 배분안 즉시 도출
- Reach Caster와의 원스톱 연계로 "예산을 얼마나 쓸지" → "얼마나 닿을지"를 하나의 플로우에서 해결

## 7.3 Reach Caster 연결 구조

- Budget Optimizer 결과 화면에서 "Reach Caster로 분석하기" CTA 제공
- 매체별 배분 예산 → Reach Predictor의 매체별 예산 입력에 자동 프리필 (수집 데이터에 한 함)
- 동일 Slot 내에서만 연결 가능 (시나리오 상속성 원칙 준수)

# 11. Expected Effects

### 1) 비딩 경쟁력 강화

Meridian 기반 고도화된 모델과 최적화된 솔루션 프로덕트를 통해 예산 최적화 결과를 즉시 제안서에 활용할 수 있어, 광고주 비딩 시 분석의 깊이와 속도 양면에서 차별화됨. 특히 데이터 부족 광고주에 대해서도 업종 모델 기반으로 즉시 제안 가능

### 2) 업무 효율화 및 리소스 최적화

기존에 결과값을 엑셀로 재가공하고 별도 리포트를 수작업하던 프로세스가 제거됨. 마케터는 시나리오 생성 → 결과 확인 → 공유까지를 하나의 플랫폼에서 완결하여, 분석 리소스를 전략적 업무에 재배치 가능

### 3) 지능형 의사결정 지원

SpinX 기반 AI 인사이트를 통해 내부 사용자뿐만 아니라 외부 사용자(광고주, 에이전시 담당자)도 복잡한 예산 배분 결과를 즉시 이해하고 의사결정에 활용 가능. 별도 컨설팅 없이 셀프 서비스 형태로 결과 해석 제공

### 4) End-to-End 미디어 플래닝 환경 구축

Budget Optimizer → Reach Caster 연결로 "얼마를 어디에 쓸지" → "얼마나 닿을지"를 하나의 플로우에서 해결. 경쟁사에 없는 차별화된 분석 여정을 제공하여 플랫폼 Lock-in 효과 확보

### 5) 플랫폼 가치 증대

ReadySet 플랫폼에 3번째 솔루션이 안착됨으로써, 단일 솔루션에서 통합 예측/분석 플랫폼으로의 포지션 전환 가속화. 향후 Ad Curator 확장 기반 확보
