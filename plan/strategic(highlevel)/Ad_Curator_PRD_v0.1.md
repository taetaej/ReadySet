# Executive Summary — Ad Curator 신규 구축

## 1. 배경 및 필요성

- 여러 매체의 데이터를 보유하고 있으나, 매체·상품 선별이 솔루션화되어 있지 않아 건별 리소스가 투입됨.
- 기존 집행 매체·상품을 중심으로 검토하다 보니, 같은 조건을 충족하는 다른 후보까지 충분히 검토하기 어려움.
- 광고주·대행사는 매체·상품 목록만으로 각 후보가 캠페인에 적합한 이유를 파악하기 어려워 AE의 추가 설명이 필요함.
- ReadySet의 탐색·선택 단계를 구축하여, 분석 → 선택 → 배분 → 예측의 미디어 플래닝 사이클을 완성할 필요가 있음.

## 2. 핵심 전략

| 축 | 전략  | 내용 |
| --- | --- | --- |
| Curation    | 조건 기반 선별과 적합도 평가 | 캠페인 조건에 맞는 후보를 추린 뒤, 보유 데이터에 기반한 상대적 적합도에 따라 Best fit / Good fit으로 구분함. 최종 선택은 사용자가 함. |
| Explanation | 선정 이유 설명과 후보 비교  | SpinX로 비정형 요구를 큐레이션 조건으로 정리함. 결과에서는 후보별 특성과 선정 이유를 광고주 눈높이로 설명하고, 추가 질문과 후보 간 비교를 지원함. |
| Integration | 솔루션 간 맥락 연결 | DataShot의 입력 맥락을 이어받고, 선택한 매체·상품과 캠페인 조건을 BudgetOpt 2.0으로 전달 |

## 3. 기대효과 (Business Impact)

- **제안 준비 리소스 절감**: 후보 선별과 선정 이유 정리에 드는 시간 단축
- **캠페인별 제안 선택지 확대**: 기존 집행 매체·상품 외에도 캠페인에 맞는 대안 발굴
- **제안 설명력 강화**: 선정 이유와 후보 간 차이를 광고주·대행사에 명확히 전달
- **플래닝 연속성 확보**: 매체·상품 선택부터 예산 배분·도달 예측까지 연결

# 1. 배경 (Background)

## 1.1 현황 (Current State)

- ReadySet은 벤치마크 분석·예산 배분·도달 예측을 지원하며, 매체·상품 선택은 AE가 플랫폼 밖에서 담당함.
- AE는 캠페인 조건에 맞춰 매체·상품 정보와 집행 이력을 검토하고, 광고주·대행사에 제안할 후보와 선정 이유를 직접 정리함.

## 1.2 문제 정의 (Problems) & 기회 요인 (Opportunities)

| #   | 문제 정의 | 기회 요인 |
| --- | --- | --- |
| 1   | **캠페인마다 반복되는 후보 선별 작업**  <br>여러 매체의 데이터를 보유하고 있으나, AE가 제안 건마다 캠페인 조건과 매체·상품 정보를 대조해 집행 가능한 후보를 직접 추려야 함. | **[Curation] 조건 기반 후보 선별**  <br>사용자가 입력한 조건을 기준으로 집행 가능한 매체·상품을 한 번에 추려, AE의 정보 확인과 후보 선별 부담을 줄임. |
| 2   | **기존 집행 매체·상품에 치우친 후보 검토**  <br>과거에 집행한 매체·상품을 중심으로 제안을 구성하면서, 같은 조건을 충족하는 다른 후보가 이번 캠페인에 얼마나 적합한지 충분히 검토하기 어려움. | **[Curation] 상대적 적합도에 따른 선택지 확대**  <br>선별된 후보를 보유 데이터 기반의 상대적 적합도에 따라 Best fit / Good fit으로 구성해, 사용자가 익숙한 후보와 그 밖의 후보를 같은 기준으로 검토하고 선택할 수 있도록 함. |
| 3   | **제안 결과만으로 파악하기 어려운 선정 이유**  <br>매체·상품 목록과 기본 정보만으로는 각 후보가 이번 캠페인에 왜 적합한지 알기 어려워, 광고주·대행사가 제안 의도를 이해하려면 AE의 추가 설명이 필요함. | **[Explanation] 선정 이유를 함께 검토하는 환경**  <br>상품 특성과 캠페인 조건에 맞는 이유를 결과에 함께 제시하고, SpinX를 통해 광고주·대행사가 궁금한 후보를 더 살펴보거나 후보 간 차이를 비교할 수 있도록 함. |
| 4   | **분석과 예산 배분 사이에서 끊기는 플래닝 흐름**  <br>ReadySet에서 데이터를 분석한 뒤 어떤 매체·상품을 사용할지 정하는 단계가 플랫폼 밖에 있어, 분석 맥락과 선택 결과가 후속 단계로 이어지지 않음. | **[Integration] End-to-End 미디어 플래닝 완성**  <br>DataShot의 입력 맥락을 Ad Curator로 이어받고, 사용자가 선택한 매체·상품과 캠페인 조건을 BudgetOpt 2.0으로 전달해 분석 → 선택 → 배분 → 예측 흐름을 연결함. |

# 2. 목적 및 목표 (Purpose & Goals)

캠페인 조건과 보유 데이터를 기반으로 매체·상품을 선별하고 선정 이유를 설명하는 과정을 솔루션화하여, ReadySet의 미디어 플래닝 사이클을 완성하는 것을 목적으로 함.

- 매체 통합 큐레이션 구축: 캠페인 조건으로 후보를 추리고, 보유 데이터에 기반한 상대적 적합도에 따라 Best fit / Good fit으로 구분
- 특성과 선정 이유 제공: 매체·상품별 특성과 이번 캠페인에 맞는 이유를 광고주 눈높이로 설명
- SpinX 적용: 비정형 요구를 큐레이션 조건으로 정리하고, 후보별 심층 설명과 후보 간 비교를 지원
- 플래닝 연속성 확보: DataShot의 입력 맥락을 이어받고, 캠페인 조건과 사용자가 선택한 매체·상품을 BudgetOpt 2.0으로 전달

# 5. UIUX

## 5.1 입력 화면

- **가이드형 기본 입력**: 브랜드(업종) → 기간 → 캠페인 목적 → 프로모션 포함 여부 순으로 필수 입력
- **상세 입력**: 프롬프트에 예시 문장(placeholder) 제공. 예: "카카오·네이버 중에서 보장형으로, 20대 여성에게 효율 좋은 상품. 월 2천만 원 정도 쓸 예정이에요"
- **파일·이미지 첨부**: RFP, 브리프 같은 문서 파일과 이미지를 함께 첨부하면 SpinX가 내용을 분석해 큐레이션 조건으로 반영

## 5.2 결과 화면

- **기준 요약**: 상단에 이번 큐레이션의 조건과 기준을 한 번에 제시
- **매체·상품 목록**: 행 단위로 매체 / 상품명 / 매체·상품 설명 / 선정 이유 / 담기 구성
- **프로모션**: 해당 행에만 붙고 순위에 영향을 주지 않음. 조건과 원문 링크를 함께 표시
- **컬렉션**: 매체·상품 목록과 같은 화면에 두어, 목록에서 담은 상품으로 바로 셋을 구성하고 확인

## 5.3 SpinX for Ad Curator

- **설명 문장 생성**: 결과 화면의 기준 요약, 설명 한 줄, 이유 한 줄은 SpinX가 생성해 화면에 바로 표시
- **딥다이브·비교 진입**: 우하단 SpinX 플로팅 버튼으로 패널을 열어, 결과를 보던 흐름 그대로 질문
  - 딥다이브: 후보 하나를 깊이 파고듦 (예: "이 상품은 왜 들어왔어?", "금융에서 많이 쓴다는 건 어느 정도야?")
  - 비교: 후보끼리 견줘봄 (예: "왜 A가 B보다 위야?", "A랑 B 중 20대 여성 성과는 어디가 좋았어?")

## 5.4 연계 CTA

- **CTA**: CTA 클릭 → 모달 호출 → 필요한 정보 입력 → 넘겨받은 맥락과 입력값을 프리필한 상태로 다음 솔루션의 생성 화면으로 이동
  - DataShot → Ad Curator: DataShot 결과 화면에 배치
  - Ad Curator → BudgetOpt 2.0: 결과 화면의 컬렉션에 배치

# 8. 기대효과 (Expected Effects)

**1) 제안 준비 리소스 절감**

AE가 캠페인마다 매체·상품 정보를 대조하고 선정 이유를 정리하는 시간을 줄여, 미디어믹스 구성과 제안 전략에 더 집중할 수 있음.

**2) 캠페인별 제안 선택지 확대**

기존에 자주 집행한 매체·상품과 다른 후보를 같은 기준으로 비교할 수 있어, 캠페인 조건에 맞는 대안을 폭넓게 검토할 수 있음.

**3) 제안 설명력 강화**

광고주·대행사가 각 후보의 선정 이유를 직접 확인하고 SpinX로 후보 간 차이를 비교할 수 있어, AE와 어떤 매체·상품을 선택할지 구체적으로 논의할 수 있음.

**4) 플래닝 연속성 확보**

매체·상품 선택부터 예산 배분·도달 예측까지 플랫폼 안에서 이어져, 솔루션 간 연속 사용과 ReadySet 활용도 향상 기대.
