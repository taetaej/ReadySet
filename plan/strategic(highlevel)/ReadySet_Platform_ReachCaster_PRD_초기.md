## 1. Project Overview

### 1.1 프로젝트 목적

본 프로젝트는 기존 기간계 시스템에 종속되어 단순히 수치를 나열하던 도구적 한계를 극복하고, 방송과 디지털을 아우르는 통합 예측 모델 및 최소한의 사용자 고려 기능을 갖춘 **독립 플랫폼으로 진화**하는 것을 목적으로 함.

- **통합 매체(방송/디지털) 도달 예측 환경 구축**: CJ ENM CIM의 방송 광고 데이터와 디지털 매체 데이터를 유기적으로 통합하여, 크로스 미디어(Cross-Media) 관점의 전방위적 도달 성과 예측 및 최적화된 미디어 믹스 환경을 구현함.
- **솔루션 독립 및 자산화**: 기간계 시스템 의존도를 탈피하여 독자적인 아키텍처를 확보함으로써, 솔루션 고유의 기술적·운영적 가치를 제고하고 변화하는 마케팅 환경에 유연하게 대응함.
- **지능형 의사결정 체계로의 패러다임 전환**: 기존의 단순 '데이터 추출기' 수준을 넘어, AI 챗봇과 실무 유즈케이스(Use-case) 기반의 기능을 중심으로 시스템을 업그레이드함. 사용자가 복잡한 가공 과정 없이 즉시 전략 수립에 활용할 수 있는 심리스(Seamless)한 지능형 분석 환경을 구축함.

### 1.2 주요 목표

| 목표 | 구체적 실행안 |
|---|---|
| 데이터 커버리지 및 예측 엔진 고도화 | ENM 방송 광고 데이터 적용 (※ 2025년 집행 데이터 기준, 현 Reach Caster 매체 커버리지는 매체수 기준 8% 수준이나 수주액 기준 80%를 상회하므로 본 프로젝트에서 매체 커버리지 확대는 제외) |

## 3. User Problem & Opportunities (AS-IS → TO-BE)

### AS-IS — 당시의 문제

**1) 솔루션 거버넌스 및 권한 체계 부재**
- 데이터 보안 치명적 결함: 개별 광고주·프로젝트별 권한 분리가 전무하여, 모든 사용자가 타인의 광고주 데이터·시나리오에 무분별하게 접근 가능.
- 계층적 구조 부재: '폴더–시나리오' 종속 관계나 버전 관리 체계가 없어 데이터가 파편화된 채 방치.
- 비교 분석 환경 미비: 생성된 시나리오와 실측 데이터를 연계할 '그룹핑' 개념이 없어 실질적 광고 성과 환류가 불가능.

**2) 사용자 유즈케이스를 백업할 기능 부재**
- 단순 데이터 출력 도구화: '시나리오 간 비교', '타겟 배리에이션 분석' 등 핵심 기능 결여.
- 사용자 경험 무시: 인사이트 도출 사고 과정(비교 → 해석 → 제안)을 시스템이 보조하지 못하고 Raw Data만 나열.

**3) 분석 기능 부재**
- 데이터 가공/분석 리소스 추가 발생: 결과값이 가공되지 않은 수치에 국한되어, 실무자가 엑셀 등으로 재가공하는 병목.
- 지능형 가이드 결여: 예측 수치의 비즈니스적 의미·최적 시나리오 가이드 제시 기능 전무.

**4) 사용성이 고려되지 않은 UI/UX (DB View 형태)**
- 비시각적 인터페이스: 'Raw DB'를 그대로 노출한 듯한 표 위주 화면으로 가독성 저하.
- 무질서한 데이터 나열: 필터링·구조화 없이 적재되어 탐색에 과도한 시간 소요.

**5) 방송·디지털 통합 리치 분석 기능 부재**
- 경쟁사는 '방송+디지털+IPTV' 통합 솔루션 운용 중이나 본 시스템은 디지털 편중 → 진정한 크로스 미디어 전략 수립 불가.
- 비딩 경쟁력 약화: 통합 리치 분석 요구 비딩 시 타사 대비 분석 깊이 열위.

### TO-BE — 세우려 한 것

1. **[Structure] 권한 및 계층 구조 확립** — 워크스페이스 기반 권한 격리 + '캠페인–하위 시나리오' 구조 도입으로 데이터 자산 보호·관리 효율 극대화.
2. **[Function] AI 기반 유즈케이스 확장** — 단순 조회를 넘어 AI 챗봇이 시나리오 비교·성과 해석·제안서 텍스트 생성까지 지원하는 심리스 분석 프로세스.
3. **[Visual] 데이터 적재 방식에서 분석 환경의 UI 전환** — DB 형태 '표'에서, 목적에 맞게 시나리오를 관리하고 즉시 비교/해석하는 직관적 UI.
4. **[Integration] 통합 미디어 믹스 분석 환경 구축** — CJ ENM CIM 데이터 연동으로 경쟁사 수준을 따라가는 통합 리치 분석 환경.

## 4. 이 문서의 위치

- 이 PRD는 **ReadySet 거버넌스의 최초 설계 의도**를 담은 출발점이다.
- TO-BE 1(권한·계층)·2(AI 유즈케이스)·3(분석 UI)은 2026에 대부분 구현됐고, 이후 IA·스펙 문서로 상세화됐다.
- 2026 회고(`plan/retrospective/2026_ReadySet_회고.md`)의 "거버넌스를 세웠다"는 이 TO-BE의 실현을 정리한 것이다.
