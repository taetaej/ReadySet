## 0. 개요

광고상품 조회(상세) 화면 상단에 **"Benchmark Analytics"** 영역으로 차트 2종을 나란히 제공한다. 선택한 업종의 과거 집행 실적을 집계해, 사용자가 "다음 캠페인을 짤 때 참고"하도록 돕는다. **순수 참고용**이며, 이 차트의 데이터로 어떤 액션(배분 조정 등)을 강제하지 않는다. "아~ 이 업종은 이렇구나" 수준의 디깅.

- **차트 1 — Cost Share**: "이 업종에선 돈을 **어디에 어떻게 나눠** 썼나?" (미디어믹스 배분 참고)
- **차트 2 — Efficiency Map**: "그렇게 나눠 담았을 때, **내가 고른 것들 중 뭐가 효율적**이었나?" (선택 상품 간 효율 비교)

두 차트는 **한 세트**다. 같은 대상(선택 매체/상품)을 "배분(비중)"과 "효율" 두 각도로 본다. 그래서 **"많이 쓴 것 ≠ 효율 좋은 것"**이라는 엇갈림이 두 차트를 오가며 자연스럽게 읽히는 것이 핵심 가치다.

### 0.1 제공 조건

- 업종 최소 단위 기준 **상품 3개 이상**(고유 상품 수)인 업종만 제공. 매체 수는 제공 조건에 포함하지 않는다(매체 뷰 토글 활성 여부에만 영향 — §1.2).
- **제공 가능 업종이 하나도 없을 때**: Benchmark Analytics 영역에 안내 문구 **"차트 생성을 위한 데이터가 충분하지 않습니다."**만 표시하고, **업종 드롭다운·매체/상품 뷰 토글·클릭/조회 탭 등 모든 컨트롤을 숨긴다.** (보여줄 업종이 없는데 빈 컨트롤을 두지 않는다 — 군더더기 제거)

### 0.2 공통 컨트롤 (두 차트 공유)

- **업종 드롭다운**: 제공 조건 충족 업종만. 선택 업종은 두 차트가 공유.
- **매체 / 상품 뷰 토글**(우상단): 두 차트가 공유. "매체 단위" ↔ "상품 단위" 전환.
- **클릭 / 조회 탭**: **차트 2 전용**(차트 1에는 영향 없음). §2.2.
- Info 툴팁: 제목 옆에 제공 기준 안내.

## 1. 차트 1 — Cost Share (광고비 비중)

> 상태: **구현 완료** (`ResultCharts.tsx`). 이관(기존 설계 유지).

| 항목 | 정의 |
|---|---|
| 질문(제목) | "광고비는 어디에 집중됐을까?" |
| 형태 | 도넛(PieChart) + 범례 |
| 시리즈/단위 | 매체 또는 매체>상품 광고비 **비중(%)** |
| 표시 상한 | 비중 상위 **6개** + 나머지 '기타' 합산 |
| 강조(그린) | 비중 1위 1개(`--bo-accent`), 나머지 무채색 opacity 단계 |
| 툴팁 | 조각 전체명 + 비중(%) |

- **광고비 비공개**: 절대 금액은 노출하지 않고 **비중(%)만** 제공. (외부 노출 고려 — 절대수 역산 불가)
- **색 규칙**: 비중 1위만 시그니처 그린, 나머지는 무채색 opacity. (강조 한 곳)

### 1.1 뷰 토글 (매체/상품)

- **상품 뷰**: 매체>상품 단위 비중.
- **매체 뷰**: 매체별 광고비 합산 비중.

### 1.2 매체 뷰 토글 비활성 규칙 (단일 매체 업종)

- **조건**: 선택 업종의 매체 종류 수(고유 매체 수)가 **1개 이하**이면 '매체' 토글을 **비활성(disabled)**.
- **왜**: 매체가 하나뿐이면 매체별 비중은 100% 1조각이라 비교 가치가 없다. 상품 단위 비교만 의미.
- **동작**: 비활성 토글은 opacity 낮춤 + `cursor: not-allowed`, hover 시 title "단일 매체 업종은 매체별 보기를 제공하지 않습니다". 클릭해도 전환 안 됨.
- **강제 상품 뷰**: 비활성인데 현재 뷰가 '매체'면(다매체 업종 보다가 단일 매체로 전환 시) 자동으로 '상품' 뷰로 되돌림.

## 2. 차트 2 — Efficiency Map (효율 포지셔닝 맵)

> 상태: **재설계 — 구현 예정** (`ResultCharts.tsx` 차트2 교체). 기존 CPC×CTR 반전 산점도를 아래 설계로 전면 갱신.

### 2.0 컨셉

- 질문(제목): **"어떤 상품이 효율적이었을까?"** / 서브: **"매체·상품별 반응률·단가 비교"**
- 주어: **내가 선택한 매체/상품** (업종 전체 평균 아님 — §2.5)
- 성격: **순수 참고 + 상대 비교.** 차트 1(비중)과 짝을 이뤄 "많이 쓴 것 ≠ 효율 좋은 것" 엇갈림을 드러낸다.
- **테이블과의 차별화**: 하단 Extracted Table은 값(숫자)의 나열이다. 이 차트는 **배치(포지셔닝)와 선택 평균 대비 상대 위치**를 보여준다 — 테이블로는 못 보는 뷰.

### 2.1 차트 정의

| 항목 | 정의 |
|---|---|
| 형태 | 2축 포지셔닝 맵(ScatterChart). 효율 영역 = **좌상단** |
| X축 | 단가 (**정방향**: 왼쪽=저렴 → 오른쪽=비쌈) |
| Y축 | 반응 (위=높음) |
| 표시 대상 | **차트 1의 상위 상품(‘기타’ 제외)과 동일 집합** (매체/상품 뷰 공유) |
| 버블 크기 | 광고비 비중 |
| 강조(그린) | **효율 포인트 1개**만 그린 + 외곽링. 나머지 무채색 (강조 한 곳) |
| 영역 틴트 | 좌상(효율 영역) 그린 틴트(`--primary`) + 우하(비효율 영역) 연한 그레이 틴트(`--foreground` 매우 옅게). **각 한 겹**, 영역 라벨 텍스트 없음 |
| 기준선 | **선택 상품 가중평균** 십자선. 차트엔 라벨 **"평균"**만 짧게 표기(정의는 Info 팝업) |
| 영역 라벨 | **없음** ("효율 스타" 등 영역 텍스트 미표기 — 오글거림·군더더기 제거). "효율 포인트"는 그린 점 + Info 설명으로 전달 |
| 토글 위치 | **클릭/조회 토글은 제목 행 우측**(ChartCard `titleRight` 슬롯) |
| 축 스타일 | muted-foreground, axisLine/tickLine 없음 (BO 패턴) |
| 툴팁 | 이름 + 반응/단가/비중 |

> steering 정합: 강조 한 곳(효율 포인트 1개 그린), 틴트 한 겹씩(좌상 그린·우하 그레이), 영역 라벨 제거(군더더기↓), "그린 = 시스템이 짚은 정답".
> **용어·정의 노출**: 차트 위에는 "평균" 한 단어만. **"평균"과 "효율 포인트"의 정의는 제목 옆 Info(ⓘ) 호버 팝업**에 적는다 (차트 면을 깨끗하게 유지).

- **표기 자릿수** (축·툴팁·라벨 공통, DataShot 전역 정책):
  - **비율(CTR·VTR): 소수 둘째 자리까지** (셋째 자리에서 반올림, `toFixed(2)`). 예: `3.42%`, `48.07%`. 단, **차트 축 눈금만 소수 1자리로 표시**(공간 절약, 실제값·툴팁·효율 포인트 계산은 2자리 유지).
  - 단가(CPC·CPV): 정수(원), 천 단위 콤마.
  - 비중: 소수 1자리(%) — 차트 1과 동일.
  - (기존 "VTR 소수 1자리" 정책은 폐기 → CTR·VTR 모두 2자리로 통일. `DataShot_DatasetDetail_Spec.md` §5.4도 동일 갱신.)
- **축 도메인(범위) 규칙**: **X축(단가)·Y축(반응) 모두 최소를 0으로 고정**한다.
  - 즉 축이 항상 원점(0,0)에서 시작한다. 0 기준으로 봐야 "절대적으로 싼지/반응이 좋은지"가 왜곡 없이 읽힌다. (최소를 데이터 최솟값으로 잡으면 작은 차이가 과장돼 보임)
  - 축 최대는 데이터 최대 + 여유 패딩(패딩 수치는 구현 코드 위임 — 예: 반응 0.4%p, 단가 60원 정도).

### 2.2 클릭 / 조회 탭 (차트 2 전용)

광고상품마다 측정 지표가 다르다(클릭 중심 / 조회 중심). 이를 **탭으로 분리**해, 각 탭 안에서는 단위가 통일된 두 지표(비율×단가)만 쓴다.

| 탭 | X축 (단가) | Y축 (반응) |
|---|---|---|
| **클릭** | 클릭당 비용 (CPC) | 클릭률 (CTR) |
| **조회** | 조회당 비용 (CPV) | 조회율 (VTR) |

- 각 탭은 **비율(%) 1개 + 단가(원) 1개** 짝. 둘 다 외부 노출 가능 지표(절대수 아님).
- **표시 대상**: 그 탭의 지표를 **가진 상품만** 등장. (클릭 탭 = 클릭 데이터 있는 상품만, 조회 탭 = 조회 데이터 있는 상품만)

### 2.3 탭 활성/비활성 규칙

- **데이터 있는 탭만 활성.** 해당 탭 지표를 가진 상품이 **0개면 그 탭 비활성(disabled)**.
- 비활성 탭이 생기면 **활성 탭을 기본 선택**한다. (예: 선택 상품이 전부 클릭 0인 조회형 → 클릭 탭 비활성, 조회 탭 자동 선택)
- **둘 다 0개**(클릭·조회 모두 없음, 순수 노출형만)면 차트 2 영역에 **"차트 생성을 위한 데이터가 충분하지 않습니다."** 안내. (매우 드문 케이스)
- 비활성 동작은 §1.2 매체 토글과 동일 패턴(opacity 낮춤 + `cursor: not-allowed`). 비활성 탭 hover title: **"데이터가 충분하지 않습니다"**.

| 조건 (입력) | 기대 결과 |
|---|---|
| 클릭 지표 가진 상품 ≥ 1 | 클릭 탭 활성 |
| 클릭 지표 가진 상품 = 0 (전부 조회형) | 클릭 탭 비활성(title "데이터가 충분하지 않습니다"), 조회 탭 자동 선택 |
| 조회 지표 가진 상품 = 0 (전부 클릭형) | 조회 탭 비활성(title 동일), 클릭 탭 자동 선택 |
| 클릭·조회 모두 0 | 차트 2 영역에 "차트 생성을 위한 데이터가 충분하지 않습니다." |

### 2.4 집계 대상 상품 선별 (모든 계산의 전제)

차트 2의 모든 계산(점 표시·기준선·효율 포인트)은 아래를 통과한 상품만 쓴다. 순서대로 거른다.

1. **탭 지표 보유**: 선택한 탭의 두 지표를 모두 측정한 상품만.
   - 클릭 탭 → **클릭수 > 0** 인 상품 (CTR·CPC 계산 가능)
   - 조회 탭 → **조회수 > 0** 인 상품 (VTR·CPV 계산 가능)
   - 클릭수(또는 조회수)가 **0이거나 값이 없는 상품은 제외**한다. (이들을 넣으면 분모 0 또는 평균 왜곡 발생)
2. **차트 1 상위 집합**: 위를 통과한 상품 중, 차트 1(Cost Share)에 표시된 상위 상품(‘기타’ 제외)만. (두 차트 세트 동기화)

> 이렇게 거른 상품 묶음을 아래에서 **"대상 상품"**이라 부른다. 대상 상품이 1개 이하이면 비교 의미가 없으므로 효율 포인트 강조는 생략한다(점만 표시).

### 2.5 기준선 (선택 평균) — 가중평균

기준 십자선은 **대상 상품의 가중평균**이다. 단순 평균이 아니라, 규모(노출·클릭)가 큰 상품이 평균에 더 반영되도록 **합계끼리 나눈다.** 아래는 그대로 계산하면 되는 산술이다.

**클릭 탭:**
```
평균 반응(CTR, %)  = (대상 상품들의 클릭수 합계) ÷ (노출수 합계) × 100
평균 단가(CPC, 원) = (대상 상품들의 광고비 합계) ÷ (클릭수 합계)
```
**조회 탭:**
```
평균 반응(VTR, %)  = (조회수 합계) ÷ (노출수 합계) × 100
평균 단가(CPV, 원) = (광고비 합계) ÷ (조회수 합계)
```
- "합계"는 **대상 상품(§2.4를 통과한 것)만** 더한다. 제외된 상품(클릭/조회 0)은 합계에도 넣지 않는다.
- 이 평균이 X축·Y축 교차점(십자선)이 된다. **차트 위 라벨은 "평균"** 한 단어만 짧게.
- **정의는 Info(ⓘ) 팝업에** 적는다: "선택한 매체/상품들의 반응·단가를 집행 규모로 가중평균한 값(업종 전체가 아닌 선택 기준)". 차트 면엔 긴 설명을 두지 않는다.
- **"업종 평균"으로 표기 금지** — 업종 전체가 아니라 선택 상품들의 평균이므로 정직하게 표기한다.
- 참고: 노출수·클릭수·광고비 같은 **절대수는 이 평균을 구하는 내부 계산에만** 쓰고, 화면에는 노출하지 않는다(외부 노출 금지 유지). 화면에 보이는 건 평균 CTR(%)·CPC(원) 결과값뿐이다.
- **향후**: 업종 전체 집행 평균 데이터를 확보하면 기준선을 "업종 평균"으로 승격 검토.

### 2.6 효율 포인트 산출 (그린 강조 1개)

대상 상품 중 **딱 1개**를 "효율 포인트"로 골라 그린 + 외곽링으로 강조한다. 나머지는 전부 무채색. 아래 순서대로 계산한다.

**1단계 — 두 지표의 최소·최대 구하기** (대상 상품 기준):
```
반응최소 = 대상 상품들의 반응값 중 가장 작은 값   (클릭 탭이면 CTR, 조회 탭이면 VTR)
반응최대 = 가장 큰 값
단가최소 = 대상 상품들의 단가값 중 가장 작은 값   (CPC 또는 CPV)
단가최대 = 가장 큰 값
```

**2단계 — 각 상품의 값을 0~1로 바꾸기 (정규화):**
```
정규화 반응 = (그 상품 반응 − 반응최소) ÷ (반응최대 − 반응최소)
정규화 단가 = (그 상품 단가 − 단가최소) ÷ (단가최대 − 단가최소)
```
- 뜻: 가장 좋은 반응(최대)은 1, 가장 나쁜 반응(최소)은 0이 된다. 단가도 똑같이 0~1로 펴진다.
- **분모가 0일 때**(모든 상품의 반응이 같거나 단가가 같아서 최대=최소): 나누기를 하지 말고 그 값은 **0.5로 둔다.**

**3단계 — "가장 이상적인 상품"과 얼마나 가까운지 거리 구하기:**
```
이상적인 상품 = 반응 1(제일 높음) · 단가 0(제일 쌈)
거리점수 = (1 − 정규화 반응)² + (정규화 단가 − 0)²
         = (1 − 정규화 반응)² + (정규화 단가)²
```
- 뜻: 반응이 높을수록 `(1 − 정규화 반응)`이 작아지고, 단가가 쌀수록 `정규화 단가`가 작아진다. 둘 다 작으면 **거리점수가 작다** = 이상적인 상품에 가깝다.
- 반응과 단가를 **똑같이 중요하게**(50:50) 본다. (한쪽에 가중치를 더 주지 않는다.)

**4단계 — 거리점수가 가장 작은 1개 선택:**
```
효율 포인트 = 거리점수가 최솟값인 상품 1개
```
- **대상 상품 전체에서** 고른다. 상품이 어느 사분면(좌상/우하 등)에 있는지는 **따지지 않는다.** 좌상(효율 영역) 밖의 상품이 효율 포인트가 될 수도 있으며, 이는 "이 선택 중 상대적으로 가장 효율에 가까운 1개"라는 의도된 동작이다.
- **동점일 때**(거리점수가 완전히 같은 상품이 둘 이상): **반응값이 더 높은 상품**을 우선. 그래도 같으면 단가가 더 싼 상품, 그래도 같으면 목록 순서상 먼저인 상품.

- **명칭·정의**: 이 그린 점을 **"효율 포인트"**라 부른다. 차트 위엔 라벨을 달지 않고(점만), **정의는 Info(ⓘ) 팝업**에 적는다: "선택 매체/상품 중 반응이 높고 단가가 낮은, 가장 효율적인 지점에 가까운 1개. 반응·단가 동등 가중 산출."

> **효율 영역(좌상 그린 틴트) ≠ 효율 포인트(그린 점)**: 좌상 영역은 "싸고 반응 좋은 구역"이라는 **공간 안내**이고, 효율 포인트는 "시스템이 고른 가장 효율적인 1개"라는 **판단**이다. 보통 그린 점은 좌상 영역 안에 떨어지지만, 안 그럴 수도 있다(그 경우 "이 선택엔 뚜렷한 효율 포인트가 좌상에 없다"는 것 자체가 참고 정보).

### 2.7 유효성 / 엣지 케이스

| # | 조건 (입력) | 기대 결과 |
|---|---|---|
| E1 | 선택한 탭의 지표를 가진 상품(클릭수 또는 조회수 > 0)이 **1개 이하** | 효율 포인트 그린 강조 **생략** (점만 표시). 비교 대상 부족 |
| E2 | **클릭수(또는 조회수)가 0·결측인 상품** | 그 탭의 **점·기준선 합계·효율 포인트에서 모두 제외** (§2.4-1) |
| E3 | 효율 포인트 거리점수 **동점** | **반응값 높은 상품** 우선 → 단가 싼 상품 → 목록 순 |
| E4 | 정규화 분모 0 (모든 상품의 반응이 같거나 단가가 같음) | 해당 축 정규화 값을 **0.5로 고정**, 다른 축으로만 거리점수 계산 |
| E5 | (클릭·조회 모두 보유 상품 0 — §2.3) | 차트 2 전체를 **"차트 생성을 위한 데이터가 충분하지 않습니다."**로 대체 |

> E2가 핵심: 클릭/조회 0 상품은 **점에서도 빠지고, 기준선 합계에서도 빠지고, 효율 포인트 후보에서도 빠진다.** 한 군데라도 넣으면 평균·정규화가 왜곡된다.

### 2.8 매체 뷰일 때

매체 뷰에선 상품이 아니라 **매체 1개가 점 1개**가 된다. 매체 안의 상품들을 먼저 합쳐서 매체 단위 값을 만든다.

- **집계 전제**: §2.4와 동일하게, 선택한 탭의 지표를 가진 상품(클릭 탭이면 클릭수 > 0)만 합친다. 클릭/조회 0 상품은 그 매체 합계에서도 제외.
- **매체 단위 값** (클릭 탭 예시, 조회 탭도 동일 구조로 조회수·CPV 사용):
```
매체 반응(CTR, %)  = (그 매체 상품들의 클릭수 합계) ÷ (노출수 합계) × 100
매체 단가(CPC, 원) = (그 매체 상품들의 광고비 합계) ÷ (클릭수 합계)
매체 광고비 비중    = (그 매체 광고비 합계) ÷ (전체 광고비 합계)   // 버블 크기용
```
- 이렇게 만든 **매체 점들**을 대상으로 기준선(§2.5)·효율 포인트(§2.6)를 **그대로 다시 계산**한다. (상품 → 매체로 단위만 바뀔 뿐 계산 방식 동일)
- 매체가 1개뿐이면 §1.2에 따라 '매체' 토글이 비활성이므로 이 뷰 자체가 안 열린다.

## 4. 스타일 / 데이터 소스

- 색/축/툴팁은 **Budget Optimizer 차트 패턴**과 동일. 시그니처 그린(`--bo-accent`) = "시스템이 짚은 정답"(비중 1위 / 효율 포인트) 한 곳에만.
- 모든 px/hsl 수치는 구현 코드 + 디자인 토큰이 단일 진실 공급원.
- **데이터 소스**: 현재 `ResultCharts` 내부 샘플(업종별 상품 실적). 실데이터 연동 시 백엔드 응답으로 교체.
- **상품 1개가 가져야 할 데이터** (차트 2 계산에 필요한 필드):

  | 필드 | 용도 | 화면 노출 |
  |---|---|---|
  | 매체명 | 매체 뷰 집계·색 그룹 | O |
  | 상품명(label) | 상품 뷰 라벨 | O |
  | 광고비 | 가중평균·비중·버블 크기 계산 | X (내부 계산만) |
  | 노출수 | 가중평균(반응) 분모 | X (내부 계산만) |
  | 클릭수 | CTR·CPC 계산, 클릭 탭 포함 판정(>0) | X (내부 계산만) |
  | 조회수 | VTR·CPV 계산, 조회 탭 포함 판정(>0) | X (내부 계산만) |
  | CTR(%) | 클릭 탭 Y축 | O |
  | CPC(원) | 클릭 탭 X축 | O |
  | VTR(%) | 조회 탭 Y축 | O |
  | CPV(원) | 조회 탭 X축 | O |

  - 노출/클릭/조회/광고비 **절대수는 내부 계산(가중평균·비중)에만** 쓰고 화면엔 노출하지 않는다. 화면엔 비율(%)·단가(원)·비중(%)만.
  - 클릭수·조회수는 "탭 포함 판정"에도 쓰인다(0이면 그 탭에서 제외 — §2.4·E2).
