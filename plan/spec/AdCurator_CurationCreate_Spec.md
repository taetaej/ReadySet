## 1. 화면 개요

### 1.1 기능 정의
Slot 안에서 새 큐레이션을 생성 요청하는 3단계 위자드 화면. **Step 1 기본 정보**에서 브랜드(업종), 캠페인 기간, 캠페인 목적, 프로모션 포함 여부를 필수로 입력하고, 캠페인 설명(텍스트 또는 브리프 파일)을 선택적으로 넣으면 SpinX가 읽고 **Step 2 상세 설정**의 선별 기준을 미리 채우며, 사용자는 기준 값을 확인·세팅하거나 기준을 추가한 뒤, **Step 3 검토 및 실행**에서 입력 내용을 최종 확인하고 생성을 요청함.

**기획 의도**
- 사용자가 캠페인 조건을 주면, 수많은 매체·상품 중 집행 가능한 후보를 추리고 적합도로 그룹핑해 줌. 입력은 "필수 기본 정보 + 선별 기준 표"로 나눠, 처음 쓰는 사용자도 기본 정보만 채우면 결과를 받고, 숙련 사용자는 기준을 세팅·추가해 정교화할 수 있게 함.
- **SpinX의 역할은 입력 보조**임. 자연어로 상품을 추천받는 흐름은 신규 플랫폼에서 다루고, 여기서는 수많은 속성·특성 라벨을 채우는 일을 도움. SpinX가 채운 값은 사용자가 확인하고 고칠 수 있음.
- 큐레이션은 생성 후 수정할 수 없고 결과가 생성 시점 기준으로 고정되므로(정책서 4.2), **생성 전에 조건을 정확히 확인할 수 있어야 함.** 

### 1.2 문서 활용처
- **개발 참고**: 프론트엔드 구현 시 입력 규칙·유효성·플로우의 기준 문서로 활용됨.
- **제품 Docs**: 본 정의서의 기능 설명·의도가 사용자 대상 기능 문서의 기반이 됨.
- **AI 기반 TC 생성**: 입력 필드·유효성(Section 3), Step 2 동작(Section 4), 네비게이션·이탈 방지(Section 6), 인터랙션 플로우(Section 7)가 테스트 케이스의 원천 데이터가 됨. 각 규칙은 조건 → 기대 결과로 검증 가능하게 작성함.

### 1.3 진입 경로

- URL: /adcurator/curation/new
- SlotBoard → Slot Home → "Ad Curator" 선택 → "New Curation"

### 1.4 위자드 구조

```
Step 1 기본 정보 (필수, 캠페인 설명은 선택) → [SpinX 캠페인 설명 분석] → Step 2 상세 설정 (선택, 선별 기준 세팅·추가) → Step 3 검토 및 실행
```

- Step 2는 선택 단계이므로 입력 없이 "다음"으로 Step 3에 진입할 수 있음. 생성 요청은 Step 3에서만 가능함.

## 2. 레이아웃

- **페이지 머리**: 제목 "새 큐레이션 생성" + 설명 "단계별로 큐레이션 정보를 입력하고 선별을 시작하세요" (BudgetOpt 2.0 "새 시나리오 생성" 머리와 같은 형식)

- **하단 네비게이션**: 취소 / 이전 / 다음 또는 생성 요청 버튼(Section 6).

- 업종 결정 방식 라디오를 전환하면 브랜드와 업종 값이 초기화됨.

### 3.2 업종 선택 방식

| 방식   | 설명        | 용도    |
| -------- | ------------------------------------------- | --------------- |
| 브랜드 선택  | 현재 Slot 광고주 하위 브랜드를 선택하면 해당 브랜드의 업종이 자동 적용됨 | 기존 브랜드 기준 큐레이션  |
| 업종 직접 선택 | 22개 업종 단순 리스트(검색 없음)에서 직접 지정. 선택 시 드롭다운이 닫힘 | 신규 브랜드 또는 업종 탐색 |

- 업종 목록: 화장품, 자동차, 식품, 건강식품, 전자제품, 패션, 여행, 게임, 이커머스, 금융, 교육, 부동산, 통신, 유통, 엔터테인먼트, 스포츠, 의료, 가전, 주류, 생활용품, 가구/인테리어, 반려동물.

### 3.3 브랜드 선택 드롭다운

- BudgetOpt 2.0의 "시나리오 생성 → 업종 선택" 컴포넌트 그대로 사용
- 검색 필드 포함(Search 아이콘, autoFocus).
- **검색 방식**: 브랜드명 부분 일치(substring), 대소문자 무시, 실시간 필터. 앞뒤 공백은 트리밍하지 않고 입력 그대로 비교함.
- 각 항목: 브랜드명 + 업종 뱃지.
- 선택 시 업종이 자동 세팅되고 드롭다운 우측에 읽기 전용 "업종 | {업종명}" 뱃지가 표시됨.
- 선택 후 검색어는 초기화되고 드롭다운이 닫힘.

### 3.4 캠페인 기간

| 항목   | 규칙              |
| ----- | --------------------------------------------------------------------------------- |
| 시작일  | 오늘부터 선택 가능. 어제 이전 날짜는 달력에서 비활성(선택 불가)          |
| 종료일  | 시작일 이후(시작일과 같은 날 가능)            |
| 최대 기간 | 시작일과 종료일을 포함해 **180일** (종료일 ≤ 시작일 + 179일). 180일을 넘는 기간을 고르면 반영하지 않고 "최대 180일까지 설정할 수 있습니다." 표시     |
| 안내 문구 | "최대 180일까지 설정할 수 있습니다." (필드 라벨 아래)        |
| 컴포넌트  | Ad Curator 전용 날짜 범위 선택기(`ACDateRangePicker`, Reach Caster 선택기와 같은 구성). 달력도 Ad Curator 전용(`ACCalendar`)을 써서 공용 `Calendar`는 수정하지 않음. 최대 기간은 선택 후 검사함 |

- **기획 의도**: 과거 날짜로는 집행할 수 없으므로 시작일을 오늘 이후로 제한하고, 평가 기준이 되는 캠페인 기간이 지나치게 길어지지 않도록 최대 180일로 제한함.

### 3.5 캠페인 목적

필드 라벨 아래 설명: "선택한 목적에 맞는 매체·상품을 선별합니다. 여러 개를 선택할 수 있습니다."

각 카드는 목적명 + 안내 문구로 구성되며, **다중 선택 토글**임(선택한 카드를 다시 누르면 해제). 선택 시 primary border + `primary/0.1` 배경(BO KPI 카드와 동일). 카드는 "인지 → 조회 → 트래픽 → 전환" 고정 순서로 배치됨.

| 목적  | 안내 문구  |
| --- | ---------------- |
| 인지  | 브랜드와 제품의 인지도 확대  |
| 조회  | 광고 영상의 시청 수 확대  |
| 트래픽 | 웹사이트·앱 방문 수 확대  |
| 전환  | 구매·가입 등 목표 행동 확대 |

- 선택 개수는 1~4개이며, 선택 순서는 결과에 영향을 주지 않음.
- **기획 의도**: 하나의 캠페인이 인지와 전환을 동시에 노리는 경우가 흔하므로 복수 선택을 허용함. 적합도 평가는 선택한 목적을 모두 반영해 종합함.

	- Slot 가시성 변경: 프로모션 포함 큐레이션이 있는 Slot은 Shared로 바꿀 수 없음

## 4. Step 2: 상세 설정

Step 2는 **선택 단계**이며, 기준이 없으면 "다음"으로 건너뛸 수 있음. 다만 표에 넣은 기준은 값을 반드시 세팅해야 함(Section 4.3).
화면 시안: `plan/mockups/adcurator_create_v2_prototype.html`(초기 시안. 최종 동작은 이 정의서와 구현 화면 기준).

**기획 의도**: 매체·상품 라벨은 수십 개 이상으로 늘어날 수 있어 모든 선택지를 펼칠 수 없음. 그래서 Step 1 캠페인 설명에서 SpinX가 찾은 기준만 표에 미리 채워 두고, 사용자는 값을 확인·수정하며, 더 필요한 기준은 [기준 추가]로 늘림.

### 4.0 용어 정의 — 속성 / 특성

Step 2의 선별 기준은 **속성**과 **특성** 두 가지로 나눔. 화면 구성·입력 방식·요약 표시가 모두 이 구분을 따름.

| 구분 | 속성 | 특성 |
|---|---|---|
| 뜻 | 매체·상품의 **정해진 스펙** | 데이터나 맥락으로 **해석한 성향·상황** |
| 판별 질문 | 상품 정보만 보고 답할 수 있는가 | 성과 데이터나 캠페인 맥락을 봐야 답할 수 있는가 |
| 화면 설명 | "매체·상품의 구성 정보로, 지원하지 않으면 제외합니다." | "매체·상품이 강한 상황과 성질로, 해당할수록 우선합니다." |
| 항목 | 소재 포맷, 매체·지면, 구매 방식, 예산, 영상 형식, 디바이스, 타게팅 지원, 과금 방식, 보장 형태 | 매체 성향(단가 하락 추세, 가성비 중심 등) / 캠페인 상황(신제품 출시, 주말 집중 등). 전체 목록은 특성 카탈로그(Section 4.4) |
| Step 2 표시 | "속성 기준" 표(Section 4.3). 편집 가능, 값 필수 | "특성 기준" 문장(Section 4.4). 읽기 전용 |
| 입력 경로 | SpinX 캠페인 설명 분석 + [기준 추가] | SpinX 캠페인 설명 분석만 |
| 선별 반영 | 값에 맞는 매체·상품만 남김(필터) | 남은 매체·상품 중 특성에 맞는 곳을 우선함(순위 조정) |

- **판별 예**: "보장형"은 상품 정보에 적혀 있으므로 속성. "단가가 내려가는 추세"는 성과 데이터를 봐야 알 수 있으므로 특성. "신제품 출시"는 캠페인 맥락이므로 특성.
- **기획 의도**: 속성은 답이 정해진 스펙이라 사용자가 직접 고르고 고칠 수 있어야 함. 특성은 SpinX가 맥락을 해석한 결과라 값 목록에서 고르는 방식이 맞지 않음. 그래서 특성은 캠페인 설명을 고쳐서만 바꾸게 하고, 화면에서는 "SpinX가 이렇게 이해했다"는 확인용으로만 보여 줌.

### 4.2 SpinX 캠페인 설명 분석

SpinX는 캠페인 설명에서 **"기준"과 "항목 값"을 파싱한 경우에만** 표에 행으로 매핑함.

| 항목 | 규칙 |
|---|---|
| 분석 시점 | Step 1에서 [다음]을 누를 때, 캠페인 설명 텍스트 또는 첨부 파일이 있으면 분석함 |
| 분석 중 | 제목 "상세 설정 (선택)" 아래 본문 자리에 로딩 표시(회전하는 SpinX 심볼 + "캠페인 설명을 분석하고 있습니다." + "찾은 속성 기준과 특성 기준을 바로 채워 드립니다."). 분석 중에는 [이전]·[다음] 비활성, [취소]는 활성 |
| 다시 분석 | Step 1로 돌아가 캠페인 설명 또는 파일을 바꾼 뒤 [다음]을 누르면 다시 분석함. 바꾸지 않았으면 분석하지 않고 이전 결과를 그대로 둠 |
| 다시 분석할 때 보존 | 속성: 사용자가 추가했거나 직접 고친 행은 그대로 둠. 이전에 SpinX가 넣고 사용자가 손대지 않은 행만 새 결과로 바꿈. 특성: 사용자가 고칠 수 없으므로 전부 새 결과로 바꿈 |
| 캠페인 설명이 없을 때 | 분석하지 않음. 빈 표("0개 속성 기준" + 빈 상태)로 시작. 특성 기준은 "설명이 없음" 문장(Section 4.4) |

**분석 결과 반영 방식**

| 경우 | 반영 |
|---|---|
| 기준과 항목 값을 함께 파싱함 | 행으로 추가하고 값을 채움. 입력 열 "SpinX" |
| 기준은 찾았지만 값이 하나로 정해지지 않음(예: 예산 "2~3천만 원") | 값이 빈 행으로 추가하고, 입력칸 아래 "SpinX 후보" + 후보 버튼(예: [2,000만 원] [3,000만 원]). 누르면 그 값이 들어가고 입력 열이 "직접 입력"으로 바뀜. 값이 들어가면 후보는 사라짐 |
| 특성 표현을 찾음(예: "신제품 출시", "주말 위주로", "단가가 내려가는 매체") | **특성 카탈로그에 정의된 특성으로 매핑된 것만** 특성 기준에 반영(Section 4.4). 카탈로그에 없는 표현은 반영하지 않고 화면에 표시하지도 않음. 같은 특성은 한 번만. 순서는 특성 카탈로그 순서 |
| 기준으로 쓸 수 없는 표현(예: Step 1과 충돌하는 "인지 목적으로", 다른 솔루션 영역인 "상품별로 예산을 얼마씩", 지원하지 않는 "20대 여성 위주로") | 반영하지 않음. 화면에 따로 안내하지 않음 |
| 아무것도 파싱하지 못함 | 행을 추가하지 않음("0개 속성 기준" + 빈 상태). 특성 기준은 "못 찾음" 문장 |

- 첨부 파일 내용 읽기는 SpinX 연동 전이라 화면 구현은 예시 브리프 문장으로 대신함.

### 4.3 속성 기준 표

| 항목 | 규칙 |
|---|---|
| 라벨 | "속성 기준" + 라벨 아래 흐린 설명 "매체·상품의 구성 정보로, 지원하지 않으면 제외합니다." |
| 대상 | 속성만(Section 4.0). 특성은 이 표에 들어가지 않음 |
| 표 구성 | Reach Caster Step 2 "광고상품(채널)" 표와 같은 구성: ① 상단 바 ② 헤더 행 ③ 행. 행이 없으면 ② ③ 대신 빈 상태 |
| 상단 바 | 왼쪽 "{N}개 속성 기준"(N = 값이 있는 행 수), 오른쪽 [기준 추가] 버튼(primary, ListPlus 아이콘. Reach Caster "광고상품 추가"와 같은 형식). 버튼 안 오른쪽에 표에 있는 기준 수 뱃지(0개면 숨김) |
| 빈 상태 | 점선 테두리 상자 안에 ListPlus 아이콘 + "'기준 추가' 버튼을 클릭하여 속성 기준을 추가하세요" (Reach Caster 광고상품 빈 상태와 같은 형식) |
| 헤더 행 | "기준명" / "상세 항목" / "입력" / (삭제 열, 제목 없음) |
| 기준명 열 | 기준 이름만 표시 |
| 상세 항목 열 | 값을 고르는 칸. 값 목록이 있는 기준: 복수 선택 드롭다운(체크박스 목록, 바깥 클릭 시 닫힘, 선택 값은 가운뎃점으로 결합, 없으면 "선택하세요"). 예산: 금액 입력(placeholder "예) 2,000", 만 원 단위, 천 단위 콤마, 숫자만, 최대 6자리) + "만 원" |
| 입력 열 | 값을 채운 주체: "SpinX"(SpinX 심볼 + 글자) / "직접 입력" / 값 없음 "—". SpinX가 채운 값을 사용자가 고치면 "직접 입력"으로 바뀜 |
| 삭제 | 모든 행에 ×. 누르면 확인 없이 삭제. 마지막 행을 지우면 빈 상태로 돌아감 |
| 행 순서 | SpinX가 넣은 행(카탈로그 순서) → 사용자가 추가한 행(추가한 순서) |
| 값 순서 | 사용자가 고른 순서와 무관하게 조건 정의(카탈로그) 순서로 표시 |

**값 필수 검사**

| 항목 | 규칙 |
|---|---|
| 규칙 | 표에 있는 기준은 상세 항목 값이 반드시 있어야 함. 기준을 넣지 않은 것(0개)은 허용 |
| 에러 표시 | 값이 빈 행의 입력칸에 destructive 테두리 + 입력칸 바로 아래 에러 문구. 값이 빈 행이 생기는 즉시 표시(SpinX가 값 없이 넣은 행, [기준 추가]로 넣은 행, 값을 모두 해제한 행) |
| 에러 문구 | 값 목록에서 고르는 기준: "항목을 선택해 주세요." / 금액을 넣는 기준(예산): "항목을 입력해 주세요." |
| [다음] | 값이 빈 행이 하나라도 있으면 비활성. 모두 채우거나 해당 행을 지우면 활성 |

- **기획 의도**: 기준을 넣어 놓고 값을 비워 두면 선별에 쓰이는지 사용자가 판단하기 어려움. 표에 있는 기준은 모두 실제로 선별에 쓰이도록 값을 필수로 함. SpinX가 확신하지 못한 값도 빈칸 + 에러로 드러나 사용자가 놓치지 않음.

### 4.4 특성 기준 (읽기 전용)

SpinX가 캠페인 설명에서 찾은 특성을 속성 기준 표 아래에 **문장 한 줄**로 알려 줌. 특성 목록·추가·삭제·수정 버튼은 없음.

| 항목 | 규칙 |
|---|---|
| 라벨 | "특성 기준" + 라벨 아래 흐린 설명 "매체·상품이 강한 상황과 성질로, 해당할수록 우선합니다." |
| 표시 | 설명 아래 1px 테두리 박스 안에 SpinX 심볼 + 안내 문장 한 줄(아래 표). 목록·칩·버튼 없음 |
| 표시하는 특성 | 특성 카탈로그에 정의된 특성 이름만. SpinX가 읽어 낸 표현을 그대로 보여 주지 않음 |
| 이름 개수 | 문장에 이름은 **최대 2개**(특성 카탈로그 순서로 앞의 2개). 3개 이상이면 "외 {N}개"(N = 전체 수 − 2) |
| 전체 확인 | "외 {N}개"로 가린 특성의 이름은 화면에 표시하지 않음. 우측 Configuration Summary에는 전체 개수만 표시(Section 4.6) |
| 바꾸는 방법 | [이전]으로 Step 1에 돌아가 캠페인 설명을 고친 뒤 [다음]을 누르면 다시 분석해 새 결과로 바뀜(Section 4.2) |
| 분석 중 | Step 2 본문 전체 로딩에 포함(따로 표시하지 않음) |
| 유효성 | 없음. 특성이 0개여도 [다음]에 영향 없음 |

**안내 문장**

| 상황 | 문구 |
|---|---|
| 1개 찾음 | "SpinX가 캠페인 설명에서 '{특성1}' 특성을 찾았습니다." |
| 2개 찾음 | "SpinX가 캠페인 설명에서 '{특성1}', '{특성2}' 특성을 찾았습니다." |
| 3개 이상 찾음 | "SpinX가 캠페인 설명에서 '{특성1}', '{특성2}' 외 {N}개 특성을 찾았습니다." |
| 캠페인 설명은 있는데 못 찾음 | "캠페인 설명에서 특성을 찾지 못했습니다. 캠페인 상황(신제품 출시, 주말 집중 등)을 입력하면 선별에 반영합니다." |
| 캠페인 설명이 없음 | "캠페인 설명을 입력하면 SpinX가 특성을 찾아 선별에 반영합니다." |

- 예: 특성 4개(신제품 출시, 크리스마스·연말, 주말 집중, 프로모션 진행) → "SpinX가 캠페인 설명에서 '신제품 출시', '크리스마스·연말' 외 2개 특성을 찾았습니다."

**특성 카탈로그(예시, 데이터팀 확정 필요)**

| 분류 | 특성 이름 |
|---|---|
| 매체 성향 | 단가 하락 추세, 가성비 중심, 프리미엄 매체, 물량 확보, 집행 경험 많음, 대형 매체, 버티컬 매체, 코어 유저 보유 |
| 캠페인 상황 | 신제품 출시, 리뉴얼, 블랙프라이데이, 크리스마스·연말, 명절, 주말 집중, 프로모션 진행, 재구매 유도 |

- 분류는 카탈로그 정리용이며 화면에는 표시하지 않음.
- **기획 의도**: 특성은 SpinX가 맥락을 해석한 결과라, 화면에서 직접 고치게 하면 캠페인 설명과 특성이 서로 어긋날 수 있음. 그래서 출처를 캠페인 설명 하나로 두고 문장 한 줄로만 알림. 표시는 우리 카탈로그에 정의된 특성으로 한정해, SpinX(LLM)가 엉뚱하게 해석한 표현이 화면·선별에 섞이지 않게 함.

### 4.5 기준 추가 다이얼로그

[기준 추가]를 누르면 열림. 크기 `md`, 최대 높이 화면의 80%.

| 항목 | 규칙 |
|---|---|
| 제목·설명 | "속성 기준 추가" / "선별에 더할 기준을 고르세요. 추가한 기준은 표에서 값을 세팅합니다." |
| 검색 | 설명 아래 검색창(placeholder "기준명 또는 상세 항목 검색", 열리면 자동 포커스). 기준 이름·설명·항목 값·관련 키워드를 부분 일치(대소문자 무시, 앞뒤 공백 트리밍)로 실시간 필터. 결과 없으면 "검색 결과가 없습니다." |
| 목록 | 표에 아직 없는 **속성**만 그룹 제목 없이 카탈로그 순서로 표시(특성은 표시하지 않음). 각 줄: 체크박스 + 기준 이름 + 기준 설명 |
| 하단 | 1px 구분선 아래 [취소] / [추가 ({N}개 선택)]. 0개면 [추가] 비활성 |
| 추가 | 고른 기준을 값이 빈 행으로 표 아래에 추가하고 닫힘(값 필수 에러가 바로 표시됨) |
| 취소·바깥 클릭·Esc | 변경 없이 닫힘 |
| 추가할 기준 없음 | "추가할 수 있는 기준이 없습니다." |

- **기획 의도**: 특성은 캠페인 설명에서만 들어오므로(Section 4.0) 다이얼로그에는 사용자가 값을 고를 수 있는 속성만 둠. 한 종류뿐이라 그룹 제목도 두지 않음.

### 4.6 Configuration Summary

영역명: **Step 2 · DETAILED SETTINGS** (Step 1 영역명 표기와 동일한 형식)

| 항목명  | 값      |
| ----- | -------------------------- |
| 속성 기준 | 속성 기준 표의 **항목 수**("{N}개", 값이 있는 행만). 1개 이상이면 아래에 기준 이름 칩 영역 표시 |
| 특성 기준 | SpinX가 찾은 특성 **전체 수**("{N}개")만 표시. 칩 영역 없음 |

- 칩 영역(속성 기준만): 연한 회색 배경 영역 안에 기준 이름(예: 매체·지면, 소재 포맷)을 칩으로 나열함. BudgetOpt 2.0 Configuration Summary의 선택 상품 칩과 같은 형식.
- 값(예: YouTube)은 표시하지 않고 기준 이름만 표시함. 값이 빈 행은 세지 않음.
- 칩은 **10개까지** 표시하고, 넘으면 마지막에 "외 {N}개"를 붙임. 순서는 조건 정의(카탈로그) 순서를 따름.
- 0개인 항목은 `—`로 표시하고 칩 영역을 표시하지 않음(Step 1 미입력 항목과 같은 표기).
- **기획 의도**: 요약은 최종 확인용이라 어떤 종류의 기준을 넣었는지만 한눈에 보이면 되고, 값 전체는 Step 2 목록에서 확인함. 칩을 10개로 제한해 항목 수가 늘어도 패널 높이가 크게 늘지 않게 함.

## 5. Step 3: 검토 및 실행

**기획 의도**: 큐레이션은 생성 후 수정할 수 없고 결과가 생성 시점 기준으로 고정됨. 잘못 입력한 채로 요청하면 복제 후 재생성해야 하므로, 요청 직전에 입력 전체를 한 번 더 확인하는 단계를 둠.

## 6. 네비게이션 제어

### 6.1 버튼 활성화 조건

| 버튼 | 위치 | 활성 조건 |
|------|------|-----------|
| 취소 | Step 1·2·3 | 항상 활성 |
| 다음 | Step 1 | `isStep1Valid` = true (false이면 `disabled`) |
| 다음 | Step 1 → 2 | SpinX 캠페인 설명 분석 중에는 비활성 |
| 다음 | Step 2 | 표에 값이 빈 행이 없으면 활성(기준 0개도 활성). 값이 빈 행이 하나라도 있으면 비활성(Section 4.3) |
| 이전 | Step 2·3 | 활성 (이전 스텝 입력값 유지). Step 2 진입 직후 SpinX 분석 중에는 비활성 |
| 생성 요청 | Step 3 | 항상 활성 (제출 중 `disabled`) |

### 6.2 버튼 스타일

| 버튼 | 클래스 | 아이콘 |
|------|--------|--------|
| 취소 | `btn btn-ghost btn-lg` | — |
| 이전 | `btn btn-secondary btn-lg` | ChevronLeft (좌측) |
| 다음 | `btn btn-primary btn-lg` | ChevronRight (우측) |
| 생성 요청 | `btn btn-primary btn-lg` | — |

### 6.3 화면 이탈 방지 (Exit Guard)

**기획 의도**: 위자드는 입력 단계가 많아 실수로 이탈하면 작성 내용이 유실된다. 입력 중 이탈 시 확인 절차를 두어 데이터 유실을 방지한다. (Reach Caster / DataShot 시나리오 생성과 동일한 공통 훅 `useExitGuard` 사용)

**활성 조건 (isDirty)**: 화면에 진입한 시점의 값과 **현재 값이 다르면** 활성화됨. 비교 대상은 Step 1 입력 필드(캠페인 설명·첨부 파일 포함)와 Step 2 "속성 기준" 표의 값이 있는 행임. 특성 기준은 캠페인 설명에서 나오므로 따로 비교하지 않음.
- 기본값(업종 결정 방식 "브랜드 선택", 프로모션 "포함", Shared Slot의 "미포함" 자동 선택)과 복제·DataShot 진입으로 채워진 프리필 값은 진입 시점 값이므로 그대로 두면 입력으로 보지 않음.
- 값을 바꿨다가 진입 시점 값으로 되돌리면 다시 비활성이 됨.
- **기획 의도**: 값이 있는지로 판단하면 기본값·프리필 때문에 아무것도 하지 않아도 경고가 뜸. 진입 시점과 비교하면 모든 진입 경로(직접·복제·DataShot)에 같은 기준을 쓰고, 사용자가 실제로 바꾼 내용이 있을 때만 경고해 불필요한 방해를 줄임.

| 이탈 경로 | 동작 |
|-----------|------|
| 브라우저 새로고침/탭 닫기 | `beforeunload` 브라우저 기본 경고 |
| 브라우저 뒤로가기 | 확인 다이얼로그 |
| 취소 버튼 / 사이드바·브레드크럼 이동 | 확인 다이얼로그 |
| 생성 요청 성공 후 이동 | Guard 해제(경고 없음) |
| Step 간 이동(다음/이전) | 이탈이 아님. Guard 미작동 |

**확인 다이얼로그**:
- 타이틀: "페이지를 떠나시겠습니까?"
- 본문: "작성 중인 내용은 저장되지 않습니다."
- 버튼: [계속 작성] (머무름) / [나가기] (이탈 진행)

## 7. 인터랙션 플로우

### 7.1 정상 플로우 (직접 생성)
1. 큐레이션명 입력 → 브랜드 선택(업종 자동 표시) → 기간 선택 → 캠페인 목적 1개 이상 선택 → (선택) 캠페인 설명 입력·브리프 첨부 → 매체 프로모션 포함 여부 선택.
2. 모든 필수 항목이 채워지면 "다음" 활성화 → Step 2(상세 설정).
3. (캠페인 설명이 있으면) SpinX 분석 → 찾은 속성 기준이 표에 채워지고, 찾은 특성은 특성 기준 문장으로 표시됨. 값 확인·수정, 후보 선택, 필요하면 [기준 추가]. 값이 빈 행이 없어야 [다음] 활성.
4. "다음" → Step 3(검토 및 실행): 우측 Configuration Summary에서 입력 내용을 최종 확인.
5. "생성 요청" → 성공 토스트 → 2초 후 목록 이동, 새 행이 Pending으로 최상단에 보임.

### 7.2 에러 플로우
1. 필수 항목 중 일부가 비어 있으면 "다음"이 비활성 상태로 유지됨. 입력을 시작한 뒤에는 비어 있는 필수 항목에 에러 메시지가 표시됨.
2. 생성 요청 실패 → 실패 토스트 → 입력값 유지 상태에서 다시 요청 가능.
3. 입력 중 이탈 시도 → 이탈 확인 다이얼로그 → [계속 작성]이면 유지, [나가기]면 이동.

### 7.3 복제 플로우
1. 목록에서 복제 → 프리필된 Step 1(캠페인 기간만 빈 상태).
2. 캠페인 기간 입력 후 필요한 항목 수정 → Step 2(상세 기준은 프리필되지 않음. 복제된 캠페인 설명이 있으면 SpinX가 다시 분석) → 다음(Step 3) → 생성 요청.

## 8. 검증 포인트 (TC 도출)

**Step 1 입력·유효성**
- 큐레이션명 미입력(공백만 포함) 상태에서 입력을 시작하면 "큐레이션명을 입력해 주세요."가 표시되는가. 1자 입력 시 사라지는가.
- 큐레이션명 50자까지 입력되고 51자째는 입력이 차단되는가. 카운터가 n/50으로 표시되는가.
- 캠페인 설명이 캠페인 목적 아래에 있고, 라벨 바로 옆에 "SpinX for Ad Curator"가 표시되는가. 안내 문구 "캠페인 내용을 적거나 브리프를 첨부해 두면, 다음 단계에서 SpinX가 매체·소재·예산 등 선별 기준을 미리 채워 드립니다."가 보이는가.
- 캠페인 설명 2,000자까지 입력되고 2,001자째는 차단되는가. 카운터가 n/2000으로 표시되는가. 비어 있어도 "다음"이 활성화되는가.
- 클립 아이콘 → 이미지 추가 / PDF 추가로 파일을 첨부하면 입력창 위쪽에 파일 칩이 표시되고 클립 아이콘이 비활성이 되는가. ×로 삭제하면 다시 첨부할 수 있는가. PDF·PNG·JPG 외 형식은 첨부되지 않고 토스트 "PDF, PNG, JPG 파일만 첨부할 수 있습니다."가 뜨는가.
- 필드 이름이 "매체 프로모션"인가.
- 업종 결정 방식 기본값이 "브랜드 선택"인가. "업종 직접 선택"으로 전환하면 브랜드·업종이 초기화되는가.
- 브랜드 미선택 시 "브랜드를 선택해 주세요.", 업종 직접 선택 모드에서 업종 미선택 시 "업종을 선택해 주세요."가 표시되는가.
- 브랜드 드롭다운에서 브랜드명 일부(대소문자 무관)를 입력하면 해당 브랜드만 노출되는가.
- 브랜드 선택 시 "업종 | {업종명}" 뱃지가 자동 표시되는가.
- 업종 직접 선택 드롭다운에 22개 업종이 노출되는가.
- 캠페인 기간: 어제 이전 날짜가 달력에서 비활성이고 누를 수 없는가. 오늘이 시작일로 선택 가능한가. 종료일 = 시작일이 유효한가.
- 캠페인 기간 경계: 시작일 + 179일(180일째)은 반영되고, 시작일 + 180일을 고르면 반영되지 않고 "최대 180일까지 설정할 수 있습니다."가 표시되는가.
- 시작일만 선택한 상태에서 "캠페인 시작일과 종료일을 모두 선택해 주세요."가 표시되는가. 안내 문구 "최대 180일까지 설정할 수 있습니다."가 보이는가.
- 캠페인 목적 카드 클릭으로 선택/해제가 토글되고, 1개·4개 선택이 모두 유효한가. 0개일 때 "최소 1개 이상의 캠페인 목적을 선택해 주세요."가 표시되는가.
- Shared Slot 진입 시 "포함"이 비활성이고 "미포함"이 자동 선택되며 안내 문구가 표시되는가. Private/Internal Slot에서는 둘 다 선택 가능한가.
- 모든 필수 항목이 충족되면 "다음"이 활성화되고, 하나라도 비면 비활성인가.
- 입력 시작 전에는 에러 메시지가 표시되지 않고, 첫 입력 이후부터 표시되는가. 기본값만 있는 상태는 입력으로 보지 않는가.

**Step 2 · 상세 설정**
- Step 2 제목 아래 단계 안내 "Step1에서 입력한 캠페인 설명을 바탕으로 SpinX가 찾은 선별 기준이 표시됩니다."가 캠페인 설명 유무와 관계없이 표시되는가. "속성 기준" 라벨 아래 "매체·상품의 구성 정보로, 지원하지 않으면 제외합니다.", "특성 기준" 라벨 아래 "매체·상품이 강한 상황과 성질로, 해당할수록 우선합니다."가 표시되는가.
- 캠페인 설명·첨부가 없으면 분석 로딩 없이 Step 2가 열리고, "0개 속성 기준" + 빈 상태("'기준 추가' 버튼을 클릭하여 속성 기준을 추가하세요")가 표시되는가. 이 상태에서 [다음]이 활성인가.
- 캠페인 설명 또는 첨부가 있으면 [다음] 후 "캠페인 설명을 분석하고 있습니다." / "찾은 속성 기준과 특성 기준을 바로 채워 드립니다." 로딩이 표시되고, 그동안 [이전]·[다음]이 비활성인가.
- 분석 후 분석 결과 개수를 알리는 별도 안내 줄이 없고, SpinX가 넣은 행은 입력 열 "SpinX"로 표시되는가.
- 기준과 값이 함께 파싱된 기준만 행으로 들어가고, 입력 열이 "SpinX"인가. 파싱되지 않은 기준은 행이 없는가.
- 속성이 하나도 파싱되지 않으면 "0개 속성 기준" + 빈 상태가 표시되는가.
- 예산이 "2~3천만 원"처럼 범위면 예산 행이 빈 값으로 들어가고 "SpinX 후보 [2,000만 원] [3,000만 원]"이 표시되는가. 후보를 누르면 값이 들어가고 입력 열이 "직접 입력"이 되며 후보가 사라지는가.
- "20대 여성", "인지 목적으로"(목적이 전환일 때), "상품별로 예산을 얼마씩"처럼 쓸 수 없는 표현은 표·특성에 들어가지 않고, 화면에 별도 안내도 없는가.
- SpinX가 채운 값을 바꾸면 입력 열이 "직접 입력"으로 바뀌는가.
- 값이 빈 행에 입력칸 빨간 테두리와 "항목을 선택해 주세요."(예산은 "항목을 입력해 주세요.")가 바로 표시되고, [다음]이 비활성인가. 값을 채우거나 행을 지우면 에러가 사라지고 [다음]이 활성인가.
- [기준 추가] 버튼 안 뱃지 숫자가 표에 있는 기준 수와 같고, 0개면 뱃지가 없는가. 상단 바 "{N}개 속성 기준"의 N이 값이 있는 행 수와 같은가.
- 모든 행에 ×가 있고 누르면 확인 없이 삭제되는가. 마지막 행을 지우면 빈 상태로 돌아가는가.
- Step 1로 돌아갔다가 캠페인 설명·첨부를 바꾸지 않고 [다음]을 누르면 다시 분석하지 않고 표가 그대로인가. 바꾸고 [다음]을 누르면 다시 분석하되 직접 입력·추가한 행은 유지되는가.
- 상세 항목 드롭다운에서 여러 값을 체크하면 가운뎃점으로 결합해 표시되고, 바깥을 누르면 닫히는가. 값 순서가 카탈로그 순서인가.
- 예산은 숫자만 입력되고 천 단위 콤마가 붙으며 6자리를 넘지 않는가.
- 캠페인 설명에 "단가가 내려가는 매체", "집행 경험이 많은 곳"처럼 매체 성향 표현만 있으면 속성 기준 표에는 행이 없고, 특성 기준 문장에만 반영되는가.

**Step 2 · 특성 기준**
- 특성 1개: "SpinX가 캠페인 설명에서 '신제품 출시' 특성을 찾았습니다." / 2개: "'신제품 출시', '주말 집중' 특성을 찾았습니다." / 3개 이상: "'{특성1}', '{특성2}' 외 {전체−2}개 특성을 찾았습니다."가 테두리 박스 안에 SpinX 심볼과 함께 한 줄로 표시되는가.
- 문장의 이름 2개가 특성 카탈로그 순서로 앞의 2개이고, 같은 특성이 두 번 세지지 않는가. 카탈로그에 없는 표현은 문장·개수에 들어가지 않는가.
- 캠페인 설명이 있는데 특성을 못 찾으면 "캠페인 설명에서 특성을 찾지 못했습니다. 캠페인 상황(신제품 출시, 주말 집중 등)을 입력하면 선별에 반영합니다."가, 캠페인 설명이 없으면 "캠페인 설명을 입력하면 SpinX가 특성을 찾아 선별에 반영합니다."가 표시되는가.
- 특성 기준 영역에 목록·칩·×·추가·수정 버튼이 없는가. 특성 0개여도 [다음]이 활성인가(속성 값 빈 행이 없을 때).
- Step 1에서 캠페인 설명을 바꾸고 [다음]을 누르면 특성이 새 분석 결과로 모두 바뀌는가. 바꾸지 않으면 그대로인가.
- 상단 바 "{N}개 속성 기준"과 [기준 추가] 뱃지에 특성 수가 포함되지 않는가.

**Step 2 · 기준 추가 다이얼로그**
- [기준 추가]를 누르면 "속성 기준 추가" 다이얼로그가 열리고 검색창에 포커스가 가며, 표에 없는 속성만 그룹 제목 없이 기준 이름 + 설명과 함께 표시되는가. 특성(단가 추세, 집행 경험 등)이 목록에 없는가.
- 검색어(예: "CPM", "보장")로 기준 이름·설명·항목 값·키워드가 부분 일치하는 기준만 남는가. 대소문자·앞뒤 공백과 무관한가. 결과가 없으면 "검색 결과가 없습니다."가 표시되는가.
- 0개 선택 시 [추가]가 비활성이고, 고르면 [추가 ({N}개 선택)]의 N이 고른 수와 같은가.
- [추가]하면 고른 기준이 값이 빈 행으로 표 아래에 추가되고 값 필수 에러가 바로 표시되는가. [취소]·바깥 클릭·Esc로 닫으면 추가되지 않는가.
- 모든 기준이 표에 있으면 "추가할 수 있는 기준이 없습니다."가 표시되는가.

**Step 3 · 검토 및 실행**
- Step 3 진입 시 생성 안내 박스와 확인 메시지 박스("요청 전에 우측 Configuration Summary에서 설정 내용을 확인해 주세요.")가 표시되는가. 입력 필드가 없는가.
- 우측 요약 Step 1이 큐레이션명 → 업종 → 캠페인 기간 → 캠페인 목적 → 캠페인 설명 → 매체 프로모션 순서로 표시되고, Step 2는 속성 기준이 항목 수("{N}개") + 기준 이름 칩(10개 넘으면 "외 {N}개"), 특성 기준이 전체 개수("{N}개")만(칩 없음) 표시되고, 0개면 `—`로 표시되며 칩 영역이 없는가. 미입력 항목은 `—`인가.
- Step 3에서 "이전"을 누르면 Step 2로 돌아가고 입력값이 유지되는가. Step 3에 "다음" 버튼이 없고 "생성 요청"이 있는가.

**생성 요청(Step 3)·이탈 방지**
- 생성 요청 클릭 시 버튼이 비활성화되고 "생성 요청 중..."으로 표시되는가(중복 클릭 방지).
- 성공 시 토스트 "큐레이션 생성 요청이 완료되었습니다."가 뜨고 2초 후 목록으로 이동하며, 새 행이 Pending으로 최상단에 보이는가. 이탈 경고가 뜨지 않는가.
- 실패 시 토스트 "큐레이션 생성 요청에 실패했습니다. 다시 시도해 주세요."가 뜨고 입력값이 유지되며 버튼이 재활성화되는가.
- 입력이 있는 상태에서 취소/뒤로가기/사이드바 이동 시 "페이지를 떠나시겠습니까?" 다이얼로그가 뜨는가. [계속 작성]은 유지, [나가기]는 이동하는가.
- 입력이 없는(또는 기본값만 있는) 상태에서는 이탈 시 다이얼로그가 뜨지 않는가. Private·Internal Slot에서 프로모션 기본값("포함")만 있어도 뜨지 않는가.
- 값을 바꿨다가 진입 시점 값으로 되돌리면 이탈 다이얼로그가 뜨지 않는가.
- 새로고침/탭 닫기 시 입력이 있으면 브라우저 기본 경고가 뜨는가.
- Step 간 이동(다음/이전)에서는 이탈 다이얼로그가 뜨지 않는가.
- 복제 진입 후 아무것도 수정하지 않고 이탈하면 이탈 다이얼로그가 뜨지 않고, 한 필드라도 수정하면 뜨는가.

## 9. 데이터 개념 및 용어 매핑

> 상세 타입 정의는 구현 코드가 단일 진실 공급원임(`src/components/adcurator/types.ts`, 생성 화면 컴포넌트는 구현 시 추가). 여기서는 규칙·플로우 이해에 필요한 개념과 용어 매핑만 정리함.

### 9.1 구조적 특징
- 캠페인 목적은 **배열**(복수 선택)로 관리하며 고정 순서로 정렬해 저장함.
- 업종 결정 방식은 `industryMode`(brand | direct)로 구분하고, 방식에 따라 `brand` 또는 `industry`만 사용자가 입력함(브랜드 선택 시 `industry`는 자동 매핑).
- Step 2 선별 기준은 행 목록으로 관리함(SpinX가 파싱해 넣은 행 + 사용자가 추가한 행). 각 행은 값을 채운 주체(source: spinx | user)를 가짐. SpinX 후보·반영 불가 안내는 행과 분리된 분석 결과로 관리함.
- 특성은 행과 분리된 이름(ID) 목록으로 관리함. 캠페인 설명 분석 결과로만 바뀌고, 다시 분석하면 통째로 교체함.

### 9.2 UI 용어 ↔ 데이터 필드

| UI 용어   | 데이터 필드    | 비고               |
| -------------- | ------------------- | ----------------------------------------------------------------------------------- |
| 큐레이션명   | name     |               |
| 캠페인 설명   | description  | 최대 2,000자 |
| 캠페인 설명 첨부 파일 | contextFile | 파일 이름 1개 |
| 업종 결정 방식   | industryMode  | brand / direct             |
| 브랜드  | brand    | 방식 = brand일 때만             |
| 업종   | industry  | 자동 매핑 또는 직접 선택             |
| 캠페인 기간  | startDate / endDate | yyyy-mm-dd              |
| 캠페인 목적  | purposes  | awareness / view / traffic / conversion (1개 이상)       |
| 매체 프로모션 포함 여부  | promotionIncluded  | boolean              |
| 속성 기준 (Step 2) | conditions   | 행: 조건(속성 라벨), 값 목록(복수 가능, 필수), source(spinx/user) |
| 특성 기준 (Step 2) | traits | 특성 ID 목록(특성 카탈로그). 읽기 전용, 캠페인 설명 분석 결과 |
| 제외 값 (Step 2) | excludes | 이 버전에서는 입력 경로 없음(항상 빈 값). 데이터 호환용 |
