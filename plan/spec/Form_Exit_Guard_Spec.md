# 생성화면 이탈 방지 정의서

## 문서 정보
- **작성일**: 2026-08-10
- **버전**: v1.0
- **적용 대상**: 시나리오 생성(CreateScenario), 슬롯 생성(CreateFolder)
- **관련 정책**: `ui-dialog-policy.md` (Dialog Size Policy)

---

## 1. 개요

사용자가 생성 화면에서 입력 도중 의도치 않게 페이지를 이탈하는 것을 방지하는 기능.
입력 내용이 존재할 때 이탈 시도 시 확인 다이얼로그를 노출하여 데이터 유실을 예방한다.

---

## 2. 적용 대상 화면

| 화면 | 컴포넌트 | URL |
|------|----------|-----|
| 시나리오 생성 | `CreateScenario.tsx` | `/reachcaster/scenario/new` |
| 슬롯 생성 | `CreateFolder.tsx` | `/slotboard/new` |

---

## 3. 이탈 감지 조건

### 3.1 활성화 조건 (Guard 활성 시점)

이탈 방지는 **사용자가 1개 이상의 필드에 값을 입력**한 시점부터 활성화된다.

**시나리오 생성 (CreateScenario)**:
```
isDirty = scenarioName 입력 || description 입력 || moduleType 선택 
       || brand 선택 || period 입력 || targetGrp 변경 
       || totalBudget 입력 || simulationUnit 선택 || 매체 선택
       || reachPredictorMedia 추가
```

**슬롯 생성 (CreateFolder)**:
```
isDirty = slotName 입력 || description 입력 || advertiser 선택 
       || visibility 변경
```

### 3.2 비활성화 조건 (Guard 해제 시점)

- 생성 요청 버튼 클릭 후 정상 제출 완료 시 → Guard 해제
- 모든 입력값이 초기 상태로 돌아간 경우 → Guard 해제

---

## 4. 이탈 트리거

다음 모든 케이스에서 이탈 방지가 작동한다:

| 트리거 | 설명 | 처리 방식 |
|--------|------|-----------|
| 브라우저 뒤로가기 | history.back, 뒤로 버튼 | 라우터 가드 + 다이얼로그 |
| 브라우저 새로고침/닫기 | F5, Cmd+W, 탭 닫기 | `beforeunload` 이벤트 (브라우저 기본 알림) |
| 사이드바(SNB) 네비게이션 | 메뉴 항목 클릭 | 라우터 가드 + 다이얼로그 |
| 브레드크럼 클릭 | 상위 경로 클릭 | 라우터 가드 + 다이얼로그 |
| 취소 버튼 | 폼 하단 "취소" 버튼 | 다이얼로그 직접 호출 |
| GNB 로고 클릭 | 홈으로 이동 | 라우터 가드 + 다이얼로그 |
| GNB 솔루션 메뉴 | 다른 솔루션 선택 | 라우터 가드 + 다이얼로그 |

## 5. 이탈 확인 다이얼로그

### 5.1 다이얼로그 사양

| 항목 | 값 |
|------|-----|
| 사이즈 | `confirm` (기본, max-width: 32rem) |
| 클래스 | `.dialog-content` |
| z-index | 기존 다이얼로그 정책과 동일 |

### 5.2 다이얼로그 내용

```
┌─────────────────────────────────────┐
│ 페이지를 떠나시겠습니까?              │
│                                     │
│ 작성 중인 내용은 저장되지 않습니다.    │
│                                     │
│          [계속 작성]  [나가기]         │
└─────────────────────────────────────┘
```

### 5.3 버튼 정의

| 버튼 | 스타일 | 동작 |
|------|--------|------|
| 계속 작성 | `btn btn-primary btn-sm` | 다이얼로그 닫기, 현재 페이지 유지 |
| 나가기 | `btn btn-secondary btn-sm` | 다이얼로그 닫기, 이탈 허용 (원래 네비게이션 수행) |

### 5.4 키보드 인터랙션

| 키 | 동작 |
|----|------|
| ESC | "계속 작성"과 동일 (페이지 유지) |
| Enter | "계속 작성"과 동일 (페이지 유지) — 실수 방지 |

---

## 6. 브라우저 새로고침/닫기 (beforeunload)

브라우저 기본 `beforeunload` 이벤트를 사용한다.
- 커스텀 메시지 불가 (브라우저 정책), 브라우저 기본 확인 다이얼로그 표시
- isDirty 상태일 때만 이벤트 등록

---

## 7. 예외 케이스

| 상황 | 동작 |
|------|------|
| 폼 제출 성공 후 리다이렉트 | Guard 해제, 이탈 허용 |
| 모든 필드 비어있을 때 | Guard 비활성, 즉시 이탈 허용 |
| Step 이동 (다음/이전) | 이탈이 아님, Guard 미작동 |
| 다이얼로그 내부 네비게이션 | 이탈이 아님, Guard 미작동 |

---

## 8. 구현 참고사항

- React Router의 navigation blocking 메커니즘 활용
- `beforeunload` 이벤트는 isDirty 상태 변경 시 동적 등록/해제
- Guard 상태는 컴포넌트 언마운트 시 자동 해제
