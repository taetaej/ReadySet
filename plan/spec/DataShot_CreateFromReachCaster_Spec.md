## A. 화면 개요

### A.1 기능 정의 · 기획 의도

Reach Caster 결과(도달·효율 분석)를 다 본 사용자가, **화면을 떠나지 않고 그 자리에서** DataShot 데이터셋 생성을 시작하도록 **생성 모달**을 띄우는 CTA를 둔다. 결과를 본 직후가 "이 업종 벤치마크 데이터를 뽑아보고 싶다"는 니즈가 가장 큰 지점이므로, 그 흐름을 끊지 않고 **세션 맥락(업종·매체·광고상품)을 그대로 들고** 생성에 진입시킨다.

- **모달의 역할 = 맥락 확인·대조 → 생성 화면 입구**: 모달은 데이터셋을 즉시 만들지 않는다. 데이터셋명·기간을 받고 매체·상품을 DataShot과 대조한 뒤, "DataShot 생성" 버튼으로 **맥락이 프리필된 생성 화면(`/datashot/new`)으로 이어준다**(§C.5). 광고상품 데이터셋은 지표 선택이 필수라, 지표는 생성 화면에서 사용자가 고른다.

- **왜 '이동'이 아니라 '모달'인가**: 기존 CTA는 `/datashot`(목록)으로 **화면을 전환**했다. 전환은 지금 보던 결과 맥락을 끊고, 목록 → New Dataset → 처음부터 입력이라는 먼 길을 돌게 한다. 모달은 **결과 위에 겹쳐** 생성 플로우를 열어, "하나의 캠페인 판단 세션" 연속성(제품 태도 §2)을 지킨다.
- **왜 맥락을 프리필하나**: 사용자가 Reach Caster에서 이미 정한 업종·매체/상품을 DataShot에서 **다시 입력하게 하면 세션이 끊긴 것**이다(제품 태도상 실패). 넘어갈 때 맥락을 채워 넘겨 "들고 간다"는 감각을 준다.
- **Reach Caster가 넘기는 맥락 2가지**: ① **업종(대)** — 데이터셋 업종으로 그대로 사용. ② **매체·상품** — "매체별 전달 내역"에서 DataShot 광고상품과 대조해 전달/제외를 보여주는 재료. (기간은 Reach Caster 값이 아니라 **모달에서 사용자가 새로 선택**한다 — 벤치마크로 보고 싶은 기간은 캠페인 기간과 다를 수 있으므로.)
- **왜 추출 기준을 광고상품으로 고정하나**: Reach Caster 맥락(매체·상품 믹스 분석)과 가장 잘 이어지는 것이 광고상품 기준 다매체 추출이다. 모달 진입 시 기본값으로 둬서 사용자가 추출 기준부터 고민하지 않게 한다.

### A.2 문서 활용처

- **개발 참고**: Reach Caster 결과 2개 화면의 CTA 교체 + 생성 모달 연결. 구현 진입점은 §F.
- **제품 Docs**: "결과를 본 뒤 바로 데이터셋을 만들 수 있다"는 사용자 동선 설명 기반.
- **AI 기반 TC 생성**: CTA·프리필·모달 규칙(§D)이 테스트 케이스 원천.

## B. 레이아웃 — CTA 존

세로 스택: **제목 → 설명 → 버튼** 순. (기존 유입 CTA 존 레이아웃을 그대로 재사용하되, 버튼 동작만 교체)

| 요소 | 노출 문구 | 비고 |
|---|---|---|
| 제목 | `{업종} 업종의 캠페인 성과는 어떨까요?` | 업종은 세션 맥락(`scenarioData.industry`) 프리필. 없으면 기본 `여행` |
| 설명 | `DataShot에서 내 업종의 캠페인 성과 데이터를 바로 만들어 확인할 수 있어요.` | "넘어가면 새로 얻게 되는 것"을 제시. (※ 기존 "이어서 확인" → "바로 만들어 확인"으로 교체 — 모달 생성 의미 반영) |
| 버튼(결과 하단 CTA) | `DataShot으로 캠페인 성과 보기` | 좌측 Database 아이콘. 클릭 시 **모달을 연다**(§C.1). 결과 화면에 상주하는 "모달 여는" 버튼이므로 기존 문구 유지 |

- **버튼 2개를 구분한다**: ① **결과 하단 CTA 버튼**(위 표) = 모달을 여는 버튼. ② **모달 푸터의 생성 버튼** = `DataShot 생성`(§C.2 푸터). 모달 푸터 버튼이 생성 화면으로 넘기는 최종 액션이다(BO 2.0 모달의 "Reach Caster 생성" 자리에 대응).
- 설명 문장은 읽는 폭 제한(약 560px)을 적용한다.
- 버튼은 프로덕트 primary(pill) 표준. 정확한 radius/height/색은 구현 코드·디자인 토큰 위임(기존 CTA 버튼과 동일 스펙 재사용).

## C. 영역별 상세

### C.1 CTA 버튼 동작

> 기존: `onClick={() => navigate('/datashot')}` (목록으로 화면 전환) → **교체**: 클릭 시 **DataShot 생성 모달을 연다**(화면 전환 없음).

- **클릭 동작**: 현재 Reach Caster 결과 화면 위에 **생성 모달을 오버레이**로 띄운다. `navigate` 호출 없음(URL 유지).
- **모달에 넘기는 값(프리필)**: §C.3 프리필 매핑대로 세션 맥락을 모달 초기값으로 전달한다.
- **hover**: 배경이 primary 미세 저채도(`--primary / 0.9`)로, (화살표 유지 시) 화살표만 소폭 미끄러짐. translateY 부양·그림자 확대 없음(절제된 인터랙션). — 기존 CTA hover 패턴 유지.

### C.2 생성 모달 구성

> UI 패턴: **Budget Optimizer 2.0 결과의 "최적화 예산으로 도달 예측하기" 모달**(`BOReachCasterEasyCreateModal.tsx`)을 차용한다. 껍데기(dialog-header 제목·설명 / 요약 박스 / 리스트 / dialog-footer 취소·생성)와 "매체별 전달 내역" 리스트·제외 뱃지·하단 안내 패턴을 그대로 따르되, 아래 DataShot 맥락으로 치환한다.

모달 세로 구성(위→아래):

1. **모달 제목 및 서브** — 제목 **"내 업종의 캠페인 성과 보기"** + 서브 **"Reach Caster의 업종·매체·광고상품을 DataShot으로 가져가 캠페인 성과를 확인합니다."**
   - **왜 이 문구인가**: CTA(제목 "{업종} 업종의 캠페인 성과는 어떨까요?" · 버튼 "DataShot으로 캠페인 성과 보기")의 **"내 업종 / 캠페인 성과"** 어휘를 그대로 이어받아 세션 연속성을 유지한다. 서브는 "Reach Caster → DataShot"으로 **맥락을 들고 넘어감**(제품 태도: 경계 없는 단일 세션)을 명시한다.
2. **데이터셋명** — 입력. 기본값 `(D/S) {Reach Caster 시나리오명}`. 사용자가 수정 가능.
3. **업종** — 읽기 표시. `{Reach Caster 선택 업종(대분류)}`. 수정 불가(세션 맥락 고정값).
4. **조회기간 입력** — **사용자가 선택.** DataShot 생성 UI의 기간 선택기를 **그대로 재사용**(월/분기 옵션 + 날짜 범위 선택). 초기값 없음(선택 전).
5. **매체별 전달 내역** — **기간 선택 전에는 미노출.** 기간 선택 후 노출(§C.4).
6. **푸터** — `취소` / **`DataShot 생성`** 버튼. "DataShot 생성"은 모달에서 데이터셋을 즉시 만드는 게 아니라, 입력·대조 결과를 **DataShot 생성 화면(`/datashot/new`)으로 프리필해 이동**시킨다(§C.5). 실제 데이터셋 생성은 생성 화면에서 사용자가 마무리한다.

- **추출 기준**: 내부적으로 **광고상품 고정**(모달에 토글 노출하지 않음). 생성되는 데이터셋은 항상 광고상품 기준.
- **왜 BO 2.0 모달을 참고하나**: 이미 "결과 → 다른 솔루션으로 맥락 전달" 상황에서 매체·상품을 대조·전달하는 검증된 패턴이다. 사용자가 BO에서 학습한 "매체별 전달 내역 + 제외 표시" 인터랙션을 그대로 재사용해 학습 비용을 없앤다.

| 입력 | 타입 | 기본값/프리필 | 수정 | 비고 |
|---|---|---|---|---|
| 데이터셋명 | 텍스트 | `(D/S) {scenarioData.name}` | 가능 | 접두사 `(D/S)` 고정, 뒤에 Reach Caster 시나리오명 |
| 업종(대) | 읽기 표시 | `{scenarioData.industry}` | 불가 | 광고상품 기준 = 대분류. Reach Caster는 업종(대)만 가지므로 그대로 사용(승격 매핑 불필요) |
| 조회기간 | 월/분기 + 날짜 범위 | 없음(선택 필수) | 가능 | DataShot 생성 UI의 기간 선택기 그대로 재사용 |
| 추출 기준 | (고정) | `광고상품` | 불가 | 모달에 노출 안 함 |

- **데이터셋명 접두사 `(D/S)`**: Reach Caster에서 넘어온 데이터셋임을 식별하기 위한 기본 접두사. 사용자가 지우거나 바꿀 수 있다(강제 아님).
- **업종은 승격 매핑 불필요**: Reach Caster가 보유한 업종은 **업종(대) 하나**이고, 광고상품 기준도 대분류만 쓰므로 레벨이 일치한다. (앞 버전에서 미결로 뒀던 "대분류 승격 매핑"은 **해소** — 둘 다 대분류)

### C.4 매체별 전달 내역 (기간 선택 후 노출)

Reach Caster가 보유한 **매체·상품**을, 선택한 **기간·업종**에 집행 데이터가 있는 **DataShot 광고상품과 대조**해 전달 가능 여부를 보여준다.

- **데이터 소스(현 단계)**: 실데이터 연동은 하지 않는다. 전달 내역은 **목업**으로 구성하며, **전달 · 미지원 제외 · 데이터 없음 제외** 세 케이스가 리스트에 함께 보이도록 샘플 행을 둔다(두 제외 뱃지가 노출되는 것이 핵심 목적). 기간·업종에 따른 실제 대조는 추후 연동.
- **노출 시점**: **기간이 선택되기 전에는 숨긴다.** 기간을 선택해야 "그 기간+업종의 DataShot 광고상품" 기준이 정해지므로, 그 전에는 대조할 수 없다. (목업 단계에서도 기간 선택을 노출 트리거로 유지.)
- **판정 (전달 / 2종 제외)**: Reach Caster의 각 매체·상품을 아래 순서로 판정한다.
  1. **미지원 제외** — DataShot이 **지원하지 않는 매체·상품**(비DIGITAL, 또는 DataShot 광고상품 체계에 없는 매체). 애초에 추출 대상이 아니다.
  2. **데이터 없음 제외** — DataShot이 **지원하는 DIGITAL 매체·상품이지만**, **선택한 업종·기간 내에 집행 데이터가 없는** 경우. 지원은 하나 그 조건에선 뽑을 데이터가 없다.
  3. **전달** — 위 둘에 해당하지 않음(지원 매체 + 선택 업종·기간에 데이터 있음). 정상 표시.
- **제외 뱃지 · 하단 설명** (BO 모달 `미지원 제외` 뱃지 패턴 차용, 2종으로 분기):

  | 제외 종류 | 뱃지 문구 | 하단 설명 |
  |---|---|---|
  | 미지원 제외 | **미지원 제외** | DataShot이 지원하지 않는 매체·상품으로, 전달되지 않습니다. |
  | 데이터 없음 제외 | **데이터 없음 제외** | 선택된 업종 및 기간 내 데이터가 없는 매체·상품으로, 전달되지 않습니다. |

  - 제외 행은 취소선 + 해당 뱃지(경고 아이콘)로 표시한다.
  - 하단 설명은 **해당 종류의 제외가 1건 이상 있을 때만** 노출한다(둘 다 있으면 두 줄, 하나만 있으면 한 줄).
- **헤더 카운트**: "전달 {N}개 · 미지원 제외 {A}개 · 데이터 없음 제외 {B}개" 식으로, 발생한 제외 종류만 이어 표기. (BO 모달 "전달 N · 미지원 제외 M" 패턴을 2종으로 확장)
- **왜 2종을 구분하나**: 제외 이유가 다르면 사용자의 다음 행동도 다르다. "미지원"은 **바꿀 수 없는 제약**(그 매체는 원래 안 됨)이고, "데이터 없음"은 **기간·업종을 바꾸면 전달될 수 있는** 조건부 제외다. 묶어버리면 "기간을 바꿔볼까?"라는 판단 기회를 뺏는다.
- **전부 제외일 때**: 전달 가능한 상품이 0개이면 **생성 화면에 넘기는 매체·상품이 없다**(프리필할 광고상품 없음). 이 경우 "DataShot 생성" 버튼은 비활성 처리한다(§D M7). — 넘길 게 없으므로 애초에 진행 불가.

### C.5 "DataShot 생성" 동작 — 생성 화면 프리필 이동

"DataShot 생성"(모달 푸터) 클릭 시, 모달의 입력·대조 결과를 **DataShot 데이터셋 생성 화면(`/datashot/new`)으로 프리필**해 이동한다. 모달에서 바로 데이터셋을 만들지 않는다 — 생성은 생성 화면에서 사용자가 지표까지 고른 뒤 마무리한다.

**생성 화면 프리필 상태**

- **Step1 (기본 정보)** — 아래가 채워진 상태로 진입:
  - 데이터셋명 = 모달 입력값(`(D/S) {시나리오명}` 또는 수정값)
  - 추출 기준 = `광고상품` (선택됨)
  - 업종 = Reach Caster 업종(대분류, 선택됨)
  - 조회기간 = 모달에서 선택한 기간
  - **지표 구성(종합/성과)만 미선택** — 사용자가 Step1에서 직접 고른다.
- **Step2 (광고상품 상세)** — 진입 시:
  - **전달된 광고상품이 매체별로 선택된 상태**(모달에서 '전달'로 판정된 매체·상품만. 제외 2종은 넘기지 않음).
  - **지표는 미선택** — 사용자가 Step2에서 직접 고른다.

- **왜 '생성'이 아니라 '생성 화면 이동'인가**: 광고상품 데이터셋은 **지표 선택이 필수**다(§Enhancement Spec). 모달은 지표를 받지 않으므로(명·기간·매체 대조까지만), 데이터셋을 완성할 수 없다. 그래서 모달은 **맥락을 프리필한 생성 화면의 입구**로 동작하고, 지표 구성·지표는 생성 화면에서 사용자가 고르게 한다. (모달을 무겁게 만들지 않고, 기존 생성 플로우를 재사용)
- **지표가 Step1·Step2 모두 미선택인 이유**: 지표 구성(Step1)·지표(Step2)는 분석 목적에 따라 사용자가 정해야 하는 값이라 Reach Caster 맥락으로 대신 채우지 않는다. "넘길 수 있는 것(명·업종·기간·광고상품)만 채우고, 판단이 필요한 것(지표)은 비워 둔다."

## E. 인터랙션 플로우

**정상 플로우**
1. 사용자가 Reach Predictor(또는 Ratio Finder) 결과를 확인 → 하단 CTA 존 도달.
2. "DataShot으로 캠페인 성과 보기"(결과 하단 CTA) 클릭 → **생성 모달 오버레이** 오픈(화면 전환 없음).
3. 모달에 데이터셋명 `(D/S) {시나리오명}`·업종(대) 프리필, 추출 기준 광고상품 고정. **조회기간은 미선택 → 매체별 전달 내역 숨김.**
4. 사용자가 조회기간(월/분기 + 날짜 범위) 선택 → **매체별 전달 내역 노출**. 그 기간·업종의 DataShot 광고상품과 Reach Caster 상품을 대조해 전달/제외 표시.
5. (데이터셋명 확인·수정 후) **"DataShot 생성"** 클릭 → `/datashot/new` 생성 화면으로 이동(프리필). Step1은 지표 구성만 미선택, Step2는 전달 광고상품 선택·지표 미선택 상태. 사용자가 지표를 골라 생성 마무리.

**분기·엣지**
- 세션 맥락에 업종이 없음 → CTA 제목 폴백(`여행`)(X2).
- 기간 미선택 상태 → 매체별 전달 내역 숨김 + 생성 불가(P4·P5).
- 비DIGITAL/미지원 매체·상품 → **미지원 제외**(M3).
- 지원 매체이나 선택 업종·기간에 데이터 없음 → **데이터 없음 제외**(M4).
- 전달 가능 상품 0개 → "DataShot 생성" 버튼 비활성(넘길 매체·상품 없음)(M7).
- 기간 변경 → 내역 재대조, 데이터 없음 제외가 전달로 바뀔 수 있음(M8).
- "DataShot 생성" 클릭 → 생성 화면 프리필 이동(T1~T4).
- 모달에서 취소/닫기 → 결과 화면 그대로 복귀(변경 없음).

## F. 공통 입력/인터랙션 규칙

- **CTA 버튼 2종 구분**: ① 결과 하단 CTA(모달 **여는** 버튼, "DataShot으로 캠페인 성과 보기") ② 모달 푸터(생성 화면으로 **넘기는** 버튼, "DataShot 생성"). 두 버튼의 역할·문구를 혼동하지 않는다.
- **버튼 스타일**: 결과 하단 CTA·모달 푸터 생성 버튼 모두 프로덕트 primary(pill) 표준. hover는 배경 미세 저채도(`--primary / 0.9`), 화살표만 소폭 미끄러짐 — translateY 부양·그림자 확대 없음(절제된 인터랙션).
- **기간 입력**: DataShot 생성 UI의 기간 선택기(월/분기 옵션 + 날짜 범위)를 **그대로 재사용**한다. 임의 입력 UI를 새로 만들지 않는다.
- **읽기 전용 값 표기**: 업종(대)은 수정 불가 값이므로 입력 필드가 아닌 읽기 표시로 둔다. (프리필 고정값)
- **모달 닫기 처리**: 취소/오버레이 클릭/닫기 시 입력값을 폐기하고 결과 화면 그대로 복귀(변경 없음).
- **스타일 위임**: 모든 px/hsl/grid 수치는 구현 코드 + 디자인 토큰이 단일 진실 공급원. 본 문서는 의도·토큰명만 서술(기간 선택기·모달 껍데기는 재사용 컴포넌트 스펙을 따름).

## G. 데이터 개념 및 용어 매핑

### G.1 세션 맥락 프리필 (Reach Caster → 모달 → 생성 화면)

| UI 항목 | 소스 (`scenarioData`) | 폴백 | 전달 경로 |
|---|---|---|---|
| CTA 제목 업종 | `scenarioData.industry` | `여행` | 결과 하단 CTA 제목 |
| 데이터셋명 | `scenarioData.name` | 빈 값 | 모달 → `(D/S) {name}` 기본값 → 생성 화면 Step1 |
| 업종(대) | `scenarioData.industry` | — | 모달 읽기 표시 → 생성 화면 Step1 업종 |
| 매체·광고상품 | Reach Caster 선택 매체·상품 | — | 모달 매체별 전달 내역 → (전달분만) 생성 화면 Step2 |
| 조회기간 | (Reach Caster 값 아님) | — | **모달에서 사용자가 신규 선택** → 생성 화면 Step1 기간 |
| 추출 기준 | (고정) | — | 항상 `광고상품` |

- **매체·상품은 '전달'로 판정된 것만** 생성 화면으로 넘어간다(제외 2종 제외). 판정 규칙은 §C.4.
- **기간은 프리필하지 않는다**: 벤치마크로 보고 싶은 기간은 캠페인 기간과 다를 수 있어, 사용자가 모달에서 직접 고른다.

### G.2 제외 판정 용어

| 용어 | 의미 | 데이터 성격 |
|---|---|---|
| 전달 | 지원 매체 + 선택 업종·기간에 데이터 있음 | 생성 화면 Step2로 프리필됨 |
| 미지원 제외 | DataShot 미지원 매체·상품(비DIGITAL 등) | 바꿀 수 없는 제약 |
| 데이터 없음 제외 | 지원 DIGITAL이나 선택 업종·기간에 데이터 없음 | 기간·업종 바꾸면 전달 가능(조건부) |

> 현 단계 전달 내역은 **목업**이다. 실제 매체·상품 ↔ DataShot 광고상품 대조 데이터 소스는 실데이터 연동 영역.

## H. 개선 제안 (이 화면 한정)

| 제안 | 내용 | 사용자 가치 | 상태 |
|---|---|---|---|
| 데이터셋명 자동 제안 고도화 | 기본 `(D/S) {시나리오명}` 외에 `{업종} {기간}` 요소를 더한 제안 | 입력 수고 감소, 식별성 ↑ | 검토 필요 |
| 지표 프리필 | Reach Caster 맥락으로 지표 구성/지표를 기본 제안(현재는 미선택으로 비움) | 생성 화면에서 지표 고르는 단계 단축 | 미채택(지표는 사용자 판단 영역이라 보류) |
| 생성 화면에서 모달로 복귀 | 생성 화면 Step에서 "다시 전달 내역 보기"로 모달 재오픈 | 프리필 재확인·기간 재선택 | 미채택 |

> 매체·상품 믹스 프리필(전달 상품 → Step2 선택)·생성 화면 이동은 **본 규칙으로 승격**(§C.5)되어 개선 제안에서 제외.
