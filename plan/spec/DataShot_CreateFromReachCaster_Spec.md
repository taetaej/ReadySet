## A. 화면 개요

### A.1 기능 정의 · 기획 의도

Reach Caster 결과(도달·효율 분석)를 다 본 사용자가, **화면을 떠나지 않고 그 자리에서** DataShot 데이터셋 생성을 시작하도록 **생성 모달**을 띄우는 CTA를 둔다. 결과를 본 직후가 "이 업종 벤치마크 데이터를 뽑아보고 싶다"는 니즈가 가장 큰 지점이므로, 그 흐름을 끊지 않고 **세션 맥락(업종·매체·광고상품)을 그대로 들고** 생성에 진입시킨다.

- **모달의 역할 = 맥락 확인·대조 → 생성 화면 입구**: 모달은 데이터셋을 즉시 만들지 않는다. 데이터셋명·기간을 받고 매체·상품을 DataShot과 대조한 뒤, "DataShot 생성" 버튼으로 **맥락이 프리필된 생성 화면(`/datashot/new`)으로 이어준다**(§C.5). 광고상품 데이터셋은 지표 선택이 필수라, 지표는 생성 화면에서 사용자가 고른다.
- **왜 맥락을 프리필하나**: 사용자가 Reach Caster에서 이미 정한 업종·매체/상품을 DataShot에서 **다시 입력하게 하면 세션이 끊긴 것**이다(제품 태도상 실패). 넘어갈 때 맥락을 채워 넘겨 "들고 간다"는 감각을 준다.


### A.2 문서 활용처

- **개발 참고**: Reach Caster 결과 2개 화면의 CTA 교체 + 생성 모달 연결. 구현 진입점은 §F.
- **제품 Docs**: "결과를 본 뒤 바로 데이터셋을 만들 수 있다"는 사용자 동선 설명 기반.
- **AI 기반 TC 생성**: CTA·프리필·모달 규칙(§D)이 테스트 케이스 원천.

### A.3 대상 화면 · 배치

| 화면 | 파일 | 배치 |
|---|---|---|
| Reach Predictor 결과 | `ReachPredictorResult.tsx` | 기본 결과 콘텐츠 맨 아래 CTA 존  |
| Ratio Finder 결과 | `RatioFinderResult.tsx` | 기본 결과 콘텐츠 맨 아래 CTA 존 |

- 두 화면 모두 **동일한 CTA 존 패턴**을 공유한다(제목 → 설명 → primary pill 버튼, 좌측 정렬 세로 스택).
- 콘텐츠 흐름과 CTA 사이는 얇은 상단 구분선(1px)으로 끊어 "결과 → 다음 액션" 리듬을 만든다.
- 우하단 상주 SpinX 플로팅 버튼과 겹치지 않도록 **좌측 정렬**(우측 끝으로 밀지 않음).

## C. 영역별 상세

### C.1 CTA 버튼 동작

- **클릭 동작**: 현재 Reach Caster 결과 화면 위에 **생성 모달을 오버레이**로 띄운다.
- **모달에 넘기는 값(프리필)**: §C.3 프리필 매핑대로 세션 맥락을 모달 초기값으로 전달한다.


### C.2 생성 모달 구성

모달 세로 구성(위→아래):

1. **모달 제목 및 서브** 
   - **제목**: 내 업종의 캠페인 성과 보기
   - **서브**: Reach Caster의 업종·매체·광고상품을 DataShot의 캠페인 성과 추출 대상으로 가져갑니다.
2. **데이터셋명**
   - 텍스트. 기본값 `(D/S) {Reach Caster 시나리오명}`
   - 사용자가 수정 가능 (데이터셋 생성시, 데이터셋명 입력 박스와 동일 UI)
3. **업종**
   - 읽기 표시. `{Reach Caster 선택 업종(대분류)}`
   - 수정 불가
4. **조회기간 입력**
   - 사용자가 선택.
   - DataShot 생성 UI의 기간 선택기를 **그대로 재사용**(월/분기 옵션 + 날짜 범위 선택).
   - 초기값 없음(선택 전).
5. **매체별 전달 내역**
   - **기간 선택 전에는 미노출.** 기간 선택 후 노출(§C.4).
6. **푸터**
    - `취소`: 모달 닫힘.
    - `DataShot 생성`:
      - 활성화 조건: 필수값 전체 입력 완료.
      - 입력·대조 결과를 **DataShot 생성 화면(`/datashot/new`)으로 프리필해 이동**(§C.5). 


### C.3 입력 항목 상세

| 입력 | 타입 | 기본값/프리필 | 수정 | 비고 |
|---|---|---|---|---|
| 데이터셋명 | 텍스트 | `(D/S) {scenarioData.name}` | 가능 | 접두사 `(D/S)`, 뒤에 Reach Caster 시나리오명. 접두사는 수정 가능. |
| 업종(대) | 읽기 표시 | `{scenarioData.industry}` | 불가 | 광고상품 기준 = 대분류. Reach Caster는 업종(대)만 가지므로 그대로 사용(승격 매핑 불필요) |
| 조회기간 | 월/분기 + 날짜 범위 | 없음(선택 필수) | 가능 | DataShot 생성 UI의 기간 선택기 그대로 재사용 |
| 추출 기준 | (고정) | `광고상품` | 불가 | 모달에 노출 안 함 |


### C.4 매체별 전달 내역 (기간 선택 후 노출)

Reach Caster 시나리오의 **매체·상품**을, 선택한 **기간·업종**에 집행 데이터가 있는 **DataShot 광고상품과 대조**해 전달 가능 여부를 보여준다.

- **노출 시점**:
  - 기간이 선택되기 전에는 숨김.
  - 기간을 선택해야 "그 기간+업종의 DataShot 광고상품" 기준이 정해지므로, 그 전에는 대조 불가.
- **판정 (전달 / 2종 제외)**: Reach Caster 시나리오의 각 매체·상품을 아래 순서로 판정.
  1. **미지원 제외** — DataShot이 **지원하지 않는 매체·상품** (DataShot 광고상품 체계에 없는 매체).
  2. **데이터 없음 제외** — DataShot이 **지원하는 DIGITAL 매체·상품이지만**, **선택한 업종·기간 내에 집행 데이터가 없는** 경우. 지원은 하나 그 조건에선 뽑을 데이터가 없다.
  3. **표시 없음** — 위 둘에 해당하지 않음(지원 매체 + 선택 업종·기간에 데이터 있음). 정상 표시.
- **제외 뱃지 · 하단 설명**

  | 제외 종류 | 뱃지 문구 | 하단 설명 |
  |---|---|---|
  | 미지원 제외 | **미지원 제외** | DIGITAL 구분 중 DataShot이 지원하지 않는 매체·상품으로, DataShot의 데이터셋 생성으로 전달되지 않습니다. |
  | 데이터 없음 제외 | **데이터 없음 제외** | 선택된 업종 및 기간 내 데이터가 없는 매체·상품으로, DataShot의 데이터셋 생성으로 전달되지 않습니다. |

  - 제외 행은 취소선 + 해당 뱃지(경고 아이콘)로 표시한다.
  - 하단 설명은 항상 노출한다.
- **헤더 카운트**: "전달 {N}개 · 미지원 제외 {A}개 · 데이터 없음 제외 {B}개" 식으로, 발생한 제외 종류만 이어 표기.
  - "미지원"은 **바꿀 수 없는 제약**(그 매체는 원래 안 됨)
  - "데이터 없음"은 **기간·업종을 바꾸면 전달될 수 있는** 조건부 제외
- **전부 제외일 때**: 전달 가능한 상품이 0개이면 **생성 화면에 넘기는 매체·상품이 없음**. 매체·광고상품 미선택 상태로 데이터셋 생성 화면으로 넘어감.

### C.5 "DataShot 생성" 동작 — 생성 화면 프리필 이동

"DataShot 생성"(모달 푸터) 클릭 시, 모달의 입력·대조 결과를 **DataShot 데이터셋 생성 화면(`/datashot/new`)으로 프리필**해 이동.

**생성 화면 프리필 상태**

- **Step1 (기본 정보)** — 아래가 채워진 상태로 진입:
  - 데이터셋명 = 모달 입력값(`(D/S) {시나리오명}` 또는 수정값)
  - 추출 기준 = `광고상품` (선택됨)
  - 업종 = Reach Caster 업종(대분류, 선택됨)
  - 조회기간 = 모달에서 선택한 기간
  - **지표 구성(종합/성과)만 미선택** — 사용자가 Step1에서 직접 고른다.
- **Step2 (광고상품 상세)** — 진입 시:
  - **전달된 광고상품이 매체별로 선택된 상태**(모달에서 '전달'로 판정된 매체·상품만. 제외 2종은 넘기지 않음).
  - **지표는 미선택** — 사용자가 Step2에서 직접 고른다.

## E. 데이터 개념 및 용어 매핑

### E.1 세션 맥락 프리필 (Reach Caster → 모달 → 생성 화면)

| UI 항목 | 소스 (`scenarioData`) | 폴백 | 전달 경로 |
|---|---|---|---|
| CTA 제목 업종 | `scenarioData.industry` | — | 결과 하단 CTA 제목 |
| 데이터셋명 | `scenarioData.name` | 빈 값 | 모달 → `(D/S) {name}` 기본값 → 생성 화면 Step1 |
| 업종(대) | `scenarioData.industry` | — | 모달 읽기 표시 → 생성 화면 Step1 업종 |
| 매체·광고상품 | Reach Caster 선택 매체·상품 | — | 모달 매체별 전달 내역 → (전달분만) 생성 화면 Step2 |
| 조회기간 | (Reach Caster 값 아님) | — | **모달에서 사용자가 신규 선택** → 생성 화면 Step1 기간 |
| 추출 기준 | (고정) | — | 항상 `광고상품` |

### E.2 제외 판정 용어

| 용어 | 의미 | 데이터 성격 |
|---|---|---|
| 전달 | 지원 매체 + 선택 업종·기간에 데이터 있음 | 생성 화면 Step2로 프리필됨 |
| 미지원 제외 | DataShot 미지원 매체·상품 | 바꿀 수 없는 제약 |
| 데이터 없음 제외 | 지원 DIGITAL 매체이나 선택 업종·기간에 데이터 없음 | 기간·업종 바꾸면 전달 가능(조건부) |
