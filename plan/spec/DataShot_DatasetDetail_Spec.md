## 1. 화면 개요

### 1.1 기본 정보

| 항목 | 내용 |
|---|---|
| 화면명 | 데이터셋 상세 (Dataset Detail) |
| 경로 | `/datashot/{id}` |
| 진입 경로 | DataShot 목록 → Completed 상태 행 클릭 |
| 접근 권한 | Admin, Marketer, Client, Agency (전 역할 조회 가능) |
| 진입 조건 | 데이터셋 상태가 `Completed`인 경우에만 접근 |
| 주요 기능 | 메타데이터 조회, 추출 데이터 테이블(필터/정렬/집계/페이지네이션), CSV Export, 복제/이동/삭제 |

### 1.2 기능 정의 및 기획 의도

데이터셋 상세는 **추출이 끝난 데이터를 실제로 들여다보고 분석하는 작업대**다. 사용자는 여기서 조건별로 데이터를 좁히고(필터), 지표 순으로 훑고(정렬), 전체·필터 기준 합계를 대조하며(집계 행) 인사이트를 얻는다.

- **왜 읽기 전용인가**: 상세 화면은 추출 결과를 "확인·분석"하는 곳이지 수정하는 곳이 아니다. 조회 조건과 결과를 바꾸려면 새 데이터셋을 만들어야 한다. 그래서 모든 조회 조건·데이터는 읽기 전용이며, 조건 변경은 복제(조건 상속) 경로로 유도한다.
- **왜 집계 행이 상단 고정인가**: 개별 행을 훑기 전에 "전체 vs 지금 필터로 좁힌 결과"의 규모·효율을 먼저 파악해야 판단이 선다. 그래서 전체/필터 두 집계 행을 데이터 위에 고정한다.
- **왜 Preview 제한이 있나**: 화면에 수천~수만 행을 그리면 느려진다. 화면은 상한(1,000행)까지만 미리보고, 전량은 CSV로 내보내 확인하게 역할을 나눈다.

### 1.3 문서 활용처

- **Docs**: 각 기능의 목적을 사용자 관점으로 서술 → 제품 문서로 재가공
- **TC**: §11 유효성 규칙 + §12 검증 포인트가 그대로 테스트 케이스 소스

## 5. Extracted Data 테이블

### 5.1 구성

섹션 타이틀("Extracted Data") 아래 카드 안에 헤더 행 → 필터 행 → 집계 행 2개 → 데이터 행 순으로 배치한다. 좌측 상단에 조건부 "필터 초기화" 버튼, 우측 상단에 "최근 데이터 업데이트" 정보를 둔다.

### 5.2 컬럼 구성

컬럼은 **좌측 Meta 영역**(텍스트 정렬 left)과 **우측 지표 영역**(정렬 right)으로 나뉘며, 지표 영역 시작에 좌측 border로 시각 구분한다.

**Meta 컬럼** (매체에 따라 동적):
| 컬럼 | 키 | 비고 |
|---|---|---|
| 기간 | period | |
| 매체 | media | |
| 업종(대) | industryLarge | |
| 업종(중) | industryMedium | |
| 업종(소) | industrySmall | |
| 광고상품 컬럼 | 매체별 동적 | Meta: 캠페인 목표·구매 유형·플랫폼·성과 목표 / 기타 매체: "광고상품" 단일 컬럼 |
| 타겟팅 옵션 | targetingOption | `targetingCategory` 존재 시에만 노출 (헤더 라벨 = 카테고리명) |

**지표 컬럼** (생성 시 선택 지표에 따라 동적, 순서: 광고비·노출수·클릭수·CPC·CPM·CTR·VTR):
| 컬럼 | 키 | 단위 |
|---|---|---|
| 광고비 | cost | 원 |
| 노출수 | impressions | 회 |
| 클릭수 | clicks | 회 |
| CPC | cpc | 원 |
| CPM | cpm | 원 |
| CTR | ctr | % |
| VTR | vtr | % |

- 모든 컬럼 정렬 가능(헤더 클릭). 단위는 값보다 작은 크기·낮은 대비로 병기.

### 5.3 정렬

| 동작 | 결과 |
|---|---|
| 헤더 클릭 | 해당 컬럼 asc 정렬 |
| 같은 헤더 재클릭 | asc ↔ desc 토글 |
| 정렬 아이콘 | 활성 컬럼에만 `ArrowUp`(asc)/`ArrowDown`(desc) |
| 숫자형 값 | 숫자 비교 정렬 |
| 문자형 값 | `localeCompare` 정렬 |

- **정렬·필터 순서**: 정렬을 먼저 적용한 뒤 필터를 건다(코드상 getSortedData → getFilteredData 순).

### 5.4 집계 행 (Summary Rows)

데이터 행 위에 2개 행을 고정한다.

| 순서 | 라벨 | 기준 |
|---|---|---|
| 1행 | "전체 데이터 ({N}개)" | 필터/정렬 무관, 전체 데이터 |
| 2행 | "필터 조회 결과 ({N}개)" | 현재 필터 적용 결과 |

- 스타일(의도): muted 배경, 소형·기본 굵기. 라벨은 첫 컬럼 중앙, Meta 컬럼 영역은 `-` 대시(중앙), 지표 컬럼은 값(우측). 2행 하단은 굵은 구분선으로 데이터 행과 분리.
- **집계 계산 규칙**:

| 지표 | 계산 |
|---|---|
| 광고비/노출수/클릭수 | SUM |
| CPC | 광고비 / 클릭수 (가중 평균) |
| CPM | (광고비 / 노출수) × 1000 |
| CTR | (클릭수 / 노출수) × 100 |
| VTR | (Σ(행 VTR/100 × 노출수) / 총 노출수) × 100 (노출 가중 평균) |

- 분모 0이면 해당 값 0. 표시 자릿수: 금액·정수는 정수 반올림, CTR 소수 2자리, VTR 소수 1자리.

### 5.5 필터 행

헤더 바로 아래. 컬럼 타입별 두 종류.

#### 5.5.1 목록형 필터 (Meta 컬럼)

| 요소 | 내용 |
|---|---|
| 트리거 | 드롭다운 버튼 (기본 표시 "전체") |
| 선택 표시 | 1개: 값 그대로 / 2개+: "{N}개 선택" / 전체 선택: "전체" |
| 드롭다운 | 검색 input + 전체 선택 체크박스 + 옵션 체크박스 목록 + (선택 시)초기화 버튼 |
| 대상 컬럼 | period, media, industryLarge/Medium/Small, objective, buyingType, platform, performanceGoal, targetingOption |

**드롭다운 내 검색 동작 (추측 방지)**:
- 매칭: 부분 일치(substring), 대소문자 무시
- 대상: 해당 컬럼의 고유값 목록
- 타이밍: onChange 실시간
- 결과 없음: "검색 결과가 없습니다" 표시
- 옵션 정렬: 고유값을 정렬해 표시

**동작**:
- 옵션 다중 선택 → 같은 컬럼 내 OR
- 전체 선택 체크박스: 해당 컬럼 전체 옵션 선택/해제
- 초기화: 해당 컬럼 선택값만 해제 (선택값 있을 때만 버튼 노출)
- **필터 변경 시 currentPage=1로 리셋**
- 외부 클릭(mousedown) 시 드롭다운 닫힘

#### 5.5.2 지표 필터 (Metric 컬럼)

| 요소 | 내용 |
|---|---|
| UI | 부등호 select + 숫자 input을 한 박스로 결합 |
| 부등호 옵션 | =, >, <, ≥, ≤ (기본값 `=`) |
| 숫자 입력 | 콤마 자동 포맷(천 단위). 숫자·소수점만 허용(그 외 문자 제거) |
| 적용 조건 | operator와 value가 **모두** 있을 때만 필터 적용 |
| 리셋 | 값 변경 시 currentPage=1 |

- 지표 필터 간 결합: 여러 지표에 값이 있으면 AND. 목록형↔지표형도 AND(교차).

### 5.6 필터 초기화

| 요소 | 내용 |
|---|---|
| 노출 조건 | 목록형 또는 지표 필터 중 하나라도 값이 있을 때 |
| 아이콘/스타일 | `RefreshCcw` + "필터 초기화", foreground 배경·background 텍스트(반전 강조) |
| 동작 | 모든 목록형·지표 필터 해제 + currentPage=1 |

### 5.7 최근 데이터 업데이트 정보

| 요소 | 내용 |
|---|---|
| 텍스트 | "최근 데이터 업데이트: {날짜}" (소형·muted) |
| Info 툴팁 | hover 시 표시 |
| 툴팁 내용 | "DataShot은 매월 5일경 전월 데이터를 정기 업데이트하며, 데이터 품질 향상을 위해 과거 데이터(최근 2년)의 보정 작업이 비정기적으로 진행될 수 있습니다." |

## 7. 다이얼로그

### 7.1 삭제 확인 다이얼로그

| 요소 | 내용 |

| 트리거 | 컨텍스트 메뉴 "삭제" |
| 타이틀 | "데이터셋을 삭제하시겠습니까?" |

| 취소 | 다이얼로그 닫기 |
| 삭제 | destructive 스타일. 삭제 실행 → 성공 토스트 → **1.5초 후 `/datashot` 이동**. 실패 시 에러 토스트 |

| 본문 | "종합 지표 데이터셋 복제를 원하실 경우, Private 또는 Internal Slot으로 이동시킨 후 다시 시도해 주세요." |
| 확인 | 다이얼로그 닫기 (복제 미실행) |

## 10. 접근 제어 및 엣지 케이스

### 10.1 접근 제어

| 시나리오 | 동작 |
|---|---|
| Completed가 아닌 상태 URL 직접 접근 | 에러 페이지 또는 목록 리다이렉트 |
| 존재하지 않는 ID 접근 | 404 처리 |
| 삭제된 데이터셋 접근 | 에러 안내 + 목록 이동 유도 |

### 10.1A 슬롯 가시성 변경에 따른 조회 제한 (Shared Slot × 종합 지표)

> 본 정책은 사용자 권한(Role)과 무관하며, 오직 **슬롯 가시성**에 따라 제어된다.

**의도**: Private/Internal 슬롯이 Shared로 바뀐 뒤, 그 하위의 **종합 지표** 데이터셋은 대외 노출을 막아야 한다. 목록/알림에서 진입을 시도하면 상세를 열지 않고 Error Toast로 안내한다.

| 항목 | 내용 |
|---|---|
| 적용 대상 | Shared로 변경된 슬롯 하위의 기존 종합 지표 데이터셋 |
| 적용 시점 | ① 목록에서 클릭해 상세 진입 시도 시 ② 알림의 생성 완료 알림 클릭 시 |
| 유저 안내 | 우측 상단 Error Toast (전체 사용자 공통) |

**Error Toast 스펙**:
| 요소 | 스펙 |
|---|---|
| 타입 | error |
| 타이틀 | "조회 제한" |
| 내용 | "종합 지표 데이터셋은 Shared Slot에서 조회가 불가능합니다. 데이터셋을 Private 또는 Internal Slot으로 이동하거나 관리자에게 문의해 주세요." |
| 자동 닫힘 | 5초 |
| 동작 | 상세 진입 차단 (목록 화면 유지) |

### 10.2 만료 상태

| 시나리오 | 동작 |
|---|---|
| Expired 데이터셋 접근 시도 | "만료된 데이터셋입니다. 동일한 조회 조건으로 재추출하려면 데이터셋을 복사하여 새로 생성해 주세요." 안내 |
| Copy 동작 | 조건 상속 → 생성 화면 진입 |

### 10.3 필터 관련

| 시나리오 | 동작 |
|---|---|
| 필터 결과 0건 | 빈 테이블(행 없음). 집계 2행은 유지(전체는 그대로, 필터 결과는 0개) |
| 필터 드롭다운 외부 클릭 | 드롭다운 닫힘 (mousedown) |
| 필터 검색 결과 없음 | "검색 결과가 없습니다" 표시 |

## 11. 유효성 / 동작 검증 규칙

그룹: **A 정렬 / B 필터 / C 집계 / D 페이지네이션 / E 접근·차단 정책 / F 액션**. 각 규칙은 `조건 → 기대 결과`로 검증 가능하게 서술한다.

| # | 그룹 | 규칙명 | 조건 → 기대 결과 |
|---|---|---|---|
| V1 | A | 정렬 시작 방향 | 헤더 클릭 → 해당 컬럼 asc |
| V2 | A | 정렬 토글 | 같은 헤더 재클릭 → asc↔desc |
| V3 | A | 타입별 정렬 | 숫자 컬럼 숫자비교 / 텍스트 컬럼 localeCompare |
| V4 | A | 정렬·필터 순서 | 정렬 적용 후 필터 적용 |
| V5 | B | 목록형 OR | 한 컬럼 다중 선택 → OR |
| V6 | B | 필터 간 AND | 서로 다른 컬럼/지표 → AND(교차) |
| V7 | B | 지표 필터 적용 조건 | operator+value 모두 있어야 적용 |
| V8 | B | 지표 콤마 포맷 | 1000 입력 → "1,000" 표시, 비숫자 제거 |
| V9 | B | 필터 변경 시 페이지 리셋 | 목록형/지표 필터 변경 → currentPage=1 |
| V10 | B | 드롭다운 검색 없음 | 검색 결과 0 → "검색 결과가 없습니다" |
| V11 | B | 필터 초기화 | 클릭 → 전 필터 해제 + currentPage=1 |
| V12 | B | 외부 클릭 닫힘 | 드롭다운 외부 mousedown → 닫힘 |
| V13 | C | 전체 집계 정확성 | 1행 값 = 전체 데이터 합산/가중평균 |
| V14 | C | 필터 집계 정확성 | 2행 값 = 필터 결과 합산/가중평균 |
| V15 | C | 집계 실시간 반영 | 필터 변경 → 2행 즉시 갱신 |
| V16 | C | 분모 0 처리 | 노출/클릭 0 → 파생지표 0 |
| V17 | D | 페이지 정보 표기 | `{start}-{end} / {total}개` 정확 |
| V18 | D | 크기 변경 리셋 | itemsPerPage 변경 → currentPage=1 |
| V19 | D | 경계 버튼 비활성 | 1페이지→첫/이전 disabled, 마지막→다음/마지막 disabled |
| V20 | E | 종합 지표 조회 차단 | Shared Slot 종합 지표 진입 시도 → "조회 제한" 토스트 + 차단 |
| V21 | E | Completed만 진입 | 다른 상태 URL 접근 → 차단/리다이렉트 |
| V22 | F | 삭제 조사 처리 | 종성 유무로 "을/를" 분기 |
| V23 | F | 삭제 성공 흐름 | 삭제 → 성공 토스트 → 1.5초 후 목록 이동 |
| V24 | F | 복제 차단 | Shared Slot 종합 지표 복제 시도 → "복제 불가 안내" |
| V25 | F | Copy Link | 클릭 → URL 클립보드 복사 + 성공 토스트 |
| V26 | F | CSV 전량 독립 | 필터/정렬과 무관하게 전체 행 다운로드 |
| V27 | F | 읽기 전용 | 상세에서 조회 조건·결과 수정 불가 |

- **에러 문구 원문(TC 기대값)**:

## 13. 데이터 개념 및 용어 매핑

| UI 용어 | 데이터 필드 / 개념 | 비고 |
|---|---|---|
| 매체 | `config.media` | 값에 따라 광고상품 컬럼 구조 분기(Meta = 4컬럼, 그 외 = 1컬럼) |
| 지표 컬럼 | `config.metrics` | 선택 지표에 따라 동적 |
| 타겟팅 옵션 컬럼 | `config.targetingCategory` / `targetingOption` | 카테고리 존재 시에만 컬럼·헤더 라벨 노출 |
| 목록형 필터 상태 | `listFilters` (컬럼키 → 선택값 배열) | 빈 배열 = 미적용 |
| 지표 필터 상태 | `metricFilters` (지표키 → {operator, value}) | 둘 다 있어야 적용 |
| 지표명 ↔ 데이터 키 | `metricToKey` (노출수→impressions 등) | 정렬·집계 시 매핑 |
| 종합/성과 지표 구분 | `purpose` (`'internal'` = 종합 지표) | 조회·복제 제한 판단 기준 |

> 타입 상세는 구현 파일 참조: `src/components/datashot/DatasetDetail.tsx`, `sampleData.ts`, `DatasetDetailModals.tsx`.
