## 1. 화면 개요

### 1.1 제품 정의
SpinX for Reach Caster는 AnXer의 Spin-off AI Agent로, Reach Caster의 시나리오 분석 결과를 기반으로 사용자에게 인사이트를 제공하는 대화형 AI 어시스턴트이다.

**기획 의도**: SpinX는 "차트를 다시 설명해주는 봇"이 아니라 "내 캠페인을 나보다 더 잘 아는 전략 파트너"다. 단순 수치 요약에 그치지 않고 서사와 발견(왜 이렇게 배분됐는가)을 주는 것이 목표다. 그래서 결과 화면의 컨텍스트를 자동으로 요약하고 추천 질문을 먼저 제시해, 사용자가 무엇을 물어야 할지 모르는 순간부터 대화가 시작되게 한다.

### 1.2 문서 활용처
- **개발 참고**: SpinX 패널의 화면 노출·인터랙션·세션/한도 처리의 기준 문서.
- **제품 Docs**: "결과에 대해 대화로 인사이트를 얻는다"는 기능 설명의 기반이 된다.
- **AI 기반 TC 생성**: 세션 생명주기·한도(월 100회/세션 10턴)·에러 처리·재시도 규칙(Section 2·3·6)이 `조건 → 기대 결과(에러 메시지 원문·입력 비활성화·HTTP 코드)`로 검증 가능하다. 에러/한도 메시지는 실제 노출 문구 그대로 기재한다.

> 프롬프팅·MCP 기능 상세는 `SpinX_MCP_사용_정책서_v0.1.md` 관할. 본 문서는 화면 노출·인터랙션을 다룬다.

### 1.3 호출 컨텍스트
- **시나리오 결과 화면**: Ratio Finder 결과, Reach Predictor 결과
- **시나리오 비교 결과 화면**: 타겟/기간/예산 비교 결과

### 1.4 세션 단위
- **세션 키**: `scenarioId × userId`(시나리오 결과) 또는 `comparisonId × userId`(비교 결과)
- 동일 시나리오를 볼 수 있는 다른 사용자도 각자의 세션으로 SpinX를 호출할 수 있음
- 한 사용자가 여러 시나리오에서 동시에 SpinX를 열 수 있으나, 화면당 1개 패널만 표시

## 2. 세션 관리

### 2.1 세션 생명주기

| 항목 | 정의 |
|------|------|
| 세션 ID | SpinX API에서 발급. 최초 패널 오픈 시 요청 |
| 유효 기간 | 세션 생성 시점부터 **14일** (336시간) |
| 잔여 시간 표시 | 입력 영역 하단에 `N일 N시간 남음` 형태로 표시 |
| 세션 이어가기 | 14일 이내 재방문 시 이전 대화 이력 + 컨텍스트 유지 |
| 세션 만료 | 14일 경과 시 자동 만료. 이전 대화 이력 조회 불가 |
| 수동 초기화 | 사용자가 초기화 버튼으로 세션 리셋 가능. 이전 이력 완전 삭제 |

### 2.2 세션 만료 조건

| 조건 | 동작 |
|------|------|
| 14일 경과 | 세션 자동 만료. 패널 오픈 시 새 세션 생성 |
| 사용자 수동 초기화 | 확인 다이얼로그 후 세션 삭제. 새 세션 생성 |
| 시나리오 비교 결과 삭제 | 해당 비교에 연결된 SpinX 세션도 함께 만료 |
| 시나리오 결과 삭제 | 해당 시나리오에 연결된 SpinX 세션도 함께 만료 |

### 2.3 세션 저장소
- 세션 ID, 생성 시점, 만료 시점 관리 필요
- 키 형식(추천): `spinx_session_{scenarioId}_{userId}` 또는 `spinx_session_comparison_{comparisonId}_{userId}`

## 3. 질문 한도

### 3.1 월간 질문 한도

| 항목 | 정의 |
|------|------|
| 한도 | 월 **100회** (운영에서 조정 가능, 기본 100) |
| 범위 | 유저 1명 = 월 최대 100회 |
| 초기화 주기 | 매월 1일 자동 리셋 |
| API 필드 | `monthlyChatCount`(현재 사용 횟수), `monthlyChatLimit`(한도, 0이면 무제한) |
| 카운트 기준 | 정상 완료된 채팅만 증가 (응답 시작 전 끊긴 경우 미증가) |
| 한도 도달 시 | HTTP 429 `SPINX_MONTHLY_LIMIT_REACHED` |

**UI 표시**:
- 입력 영역 하단에 `Usage {count} / {limit}` 텍스트 표시
- 호버 시 툴팁: "월간 질문 한도 — 매월 이용 가능한 SpinX 질문 횟수입니다. 매월 1일에 자동으로 초기화됩니다."
- 면책 문구와 한 줄에 좌우 배치(좌: 면책, 우: Usage)

**한도 도달 시 입력 비활성화**:
- textarea `disabled` 처리
- placeholder: "월간 질문 한도(100회)에 도달했습니다. 다음 달에 다시 이용해 주세요."
- 전송 버튼 비활성화(흐리게 + not-allowed)
- 모델 선택, 세션 잔여시간은 정상 표시 유지

### 3.2 세션 질문 한도 (턴 제한)

| 항목 | 정의 |
|------|------|
| 한도 | 세션 1개 = 최대 **10턴** |
| 범위 | 세션당 (대화 초기화 시 리셋) |
| API 필드 | `turnCount`(현재 턴 수), `turnLimit`(한도) |

| 초기화 | 대화 초기화 시 새 세션 시작으로 리셋 |

**한도 도달 시 입력 비활성화**:
- textarea `disabled` 처리
- placeholder: "세션 질문 한도(10개)에 도달했습니다. 대화 초기화 후 이용해 주세요."
- 전송 버튼 비활성화
- 모델 선택, 세션 잔여시간은 정상 표시 유지

## 5. 화면 구성

### 5.1 SpinX 호출 버튼 (SpinXButton)

**위치**: 시나리오 결과 화면 우측 하단 고정. 패널 열림 시 패널 폭만큼 좌측으로 이동(패널과 동일 이징으로 동기화). 정확한 오프셋·크기는 구현 코드 기준.

**구성**: 원형 버튼, 고정 어두운 배경(다크모드 무관), 다크모드에서는 옅은 테두리 추가. 내부는 SpinXSymbol(모션 시스템). 호버 시 그림자 강조, 클릭 시 미세 축소. 색·수치는 디자인 토큰/구현 코드 기준.

**SpinXSymbol 모션 시스템**:

| 상태 | 설명 | 전환 조건 |
|------|------|-----------|
| idle | 정지 상태 | 기본 상태 |
| hover | 마우스 오버(패널 닫혀 있을 때만) | mouseEnter(패널 닫힘) |
| engage | 패널 열릴 때 | 패널 open → 약 0.9초 후 active로 전환 |
| active | 패널 열린 상태 | engage 후 자동 전환 |
| settle | 패널 닫힐 때 | 패널 close → 약 1.1초 후 idle로 전환 |

**전환 흐름**: `idle → hover → engage → active → settle → idle`

### 5.4 메시지 영역 [B]

세로 스크롤 영역. 메시지는 아래에서 위로 쌓이며, 새 메시지 추가 시 부드럽게 자동 스크롤(`scrollIntoView({ behavior: 'smooth' })`).

#### 5.4.1 컨텍스트 요약 (패널 오픈 시 자동 수행)
패널이 열리면 현재 시나리오/비교 결과의 핵심 데이터를 자동 요약해 표시한다.

- **모듈 뱃지 + 시나리오명**: 뱃지(foreground 배경 + background 텍스트)에 모듈 아이콘(Scale=Ratio Finder / Target=Reach Predictor) + 시나리오명.
- **요약 카드**: muted 배경 카드. 우측 상단 복사 버튼(Copy → 클릭 시 Check, 약 2초 후 복귀). "요약" 타이틀 + 요약 내용.
- 시나리오 결과 요약 / 비교 결과 요약 내용은 각각 별도 프롬프트로 생성.

#### 5.4.2 추천 질문 (패널 오픈 시 자동 수행)
컨텍스트 요약 아래에 추천 질문 4개를 버튼으로 표시.
- "추천 질문" 섹션 타이틀 + 질문 버튼 목록(세로 스택). 버튼은 얇은 테두리, 호버 시 muted 배경 + foreground 테두리.
- **클릭 동작**: 해당 질문 텍스트를 자동 전송(짧은 딜레이 후 handleSend).
- 질문 생성 기준은 별도 프롬프트. 추천 질문 아래 "방금 전" 타임스탬프.

#### 5.4.3 사용자 메시지
- 우측 정렬. primary 배경 + primary-foreground 텍스트 버블(최대 폭 제한). 하단 우측 타임스탬프.

#### 5.4.4 AI 응답 메시지
- 좌측 정렬(전체 너비). foreground 텍스트, 하단 타임스탬프. 호버 시 복사 버튼(Copy/Check).

**특수 응답 타입**:

| 타입 | 표시 방식 |
|------|-----------|
| 텍스트 | 마크다운 스타일 렌더링(볼드·리스트·줄바꿈) |
| 차트 | Recharts 기반 인라인 차트(ComposedChart, Bar + Line) |
| 에러 | muted 배경 카드, AlertCircle 아이콘 + 에러 메시지 |
| 모델 변경 알림 | 중앙 정렬 pill 뱃지(muted 옅은 틴트) |

- **차트 응답**: muted 배경 카드 안에 차트 타이틀 + 설명 + Recharts ComposedChart(Bar + Line). 색은 차트 팔레트/디자인 토큰 기준(TVC 무채색, Digital 시그니처 그린 계열, Reach 라인). 하단 범례.
- **에러 응답**: muted 배경 카드, AlertCircle(destructive) + 에러 텍스트 + 재시도 버튼(RefreshCw + "다시 시도"). 재시도 소진 시 흐리게 + not-allowed.

#### 5.4.5 역질문 UI (Clarifying Question) + 타이머
SpinX가 역질문을 보낼 때 옵션 선택 UI와 자동 건너뛰기 타이머를 표시한다.

- **자동 건너뛰기 타이머**: **25초** 프로그레스 바(width 100% → 0%, 선형). 만료 시 자동 "건너뛰기" 실행. 전송/건너뛰기 시 타이머 정리.
- **역질문 UI 구성**(SpinXClarifying.tsx): 옵션 버튼 목록(선택지) + 직접 입력 필드(자유 텍스트) + 건너뛰기 버튼.

#### 5.4.6 출처 표시 — 웹 검색 출처 (Web Sources)
웹 검색 기반 응답에 출처를 아코디언으로 표시.
- **헤더**: Globe 아이콘 + "웹 검색 결과 N개"(muted-foreground) + 화살표(ChevronRight, 펼침 시 회전). 호버 시 foreground.
- **펼침 목록**: 각 소스는 링크(`<a>`) — 파비콘 + 제목(말줄임) + URL(말줄임). 호버 시 foreground. 클릭 시 새 탭(`target="_blank"`, `rel="noopener noreferrer"`).

#### 5.4.7 출처 표시 — RAG 참고 문서 (RAG Sources)
내부 문서 검색 기반 응답에 참고 문서를 아코디언으로 표시.
- **헤더**: FileText 아이콘 + "참고 문서 N개" + 화살표(회전 동일).
- **펼침 목록**: 문서 타입 아이콘(pdf/docx=FileText, url=Globe) + 문서 제목 + 요약. 각주 클릭 시 해당 문서 하이라이트(primary 옅은 틴트).

#### 5.4.8 각주 (Footnotes)
응답 텍스트 내 `[1]`, `[2]` 등을 인라인 뱃지로 렌더링. 기본은 옅은 무채색 배경, 활성 시 foreground 배경으로 반전. 위첨자 정렬.

**각주 클릭 동작**:
1. 해당 메시지의 RAG 아코디언 자동 펼침(`expandedRagSources` Set에 추가)
2. 각주 번호에 해당하는 문서 하이라이트(primary 옅은 틴트)
3. 각주 뱃지 활성 상태로 변경
4. 외부 클릭 시 하이라이트 해제

### 5.5 입력 영역 [C]

```
┌──────────────────────────────────┐
│ [첨부 미리보기]  ← 첨부 있을 때만  │
├──────────────────────────────────┤
│ [첨부][모델▾]  메시지 입력...  [▲/■] │
├──────────────────────────────────┤
│ 세션 잔여: N일 N시간               │
└──────────────────────────────────┘
```
- 상단 얇은 구분선, card 배경. 정확한 여백은 디자인 토큰 기준.

#### 5.5.1 입력 필드
| 요소 | 동작 |
|------|------|
| textarea | 자동 높이 조절(최대 4줄). Enter: 전송, Shift+Enter: 줄바꿈 |
| placeholder | "메시지를 입력하세요..." |
| 전송 버튼(ArrowUp, 원형, primary 배경) | 메시지 전송. 입력 없으면 흐리게 |
| 중지 버튼(Square, 원형, destructive 배경) | 로딩 중일 때만 표시. 응답 생성 중지 |

- 기본은 ArrowUp(전송), 로딩 중에는 Square(중지)로 전환.

#### 5.5.2 첨부 기능
- **트리거**: Paperclip 아이콘 버튼(ghost). 입력 필드 상단에 첨부 메뉴(팝오버) 표시.

| 항목 | 아이콘 | 허용 형식 | 크기 제한 |
|------|--------|-----------|-----------|
| 이미지 첨부 | ImageIcon | jpg, png, gif, webp | 10MB |
| PDF 첨부 | FileText | pdf | 20MB |
| URL 첨부 | Globe | https:// URL | — |

- **첨부 미리보기**(입력 필드 상단): 파일명 + 크기 또는 URL(말줄임) + 제거(X) 버튼. muted 배경 박스.
- **URL 입력 다이얼로그**: URL 입력(placeholder "https://..."), 확인/취소 버튼. **https:// 프로토콜만 허용**.

#### 5.5.3 모델 선택
- **트리거**: 현재 모델명 드롭다운 클릭. 메뉴는 입력 필드 상단에서 위로 펼침(bottom-up).

**사용 가능 모델**:

| Provider | 모델명 | 표시명 | 설명 |
|----------|--------|--------|------|
| Anthropic | claude-sonnet-4.6 | Claude Sonnet 4.6 | 데이터 해석 · 전략 수립 (**기본 선택**) |
| OpenAI | gpt-5-4 | GPT 5-4 | 복잡한 추론 · 심층 분석 |
| OpenAI | gpt-5-4-mini | GPT 5-4 mini | 빠른 질의응답 · 콤팩트 분석 |

- 각 항목: Provider + 모델명 + 설명, 선택 항목에 Check 아이콘(primary).
- **모델 변경 동작**: 즉시 변경(확인 다이얼로그 없음) → 대화 스레드에 시스템 메시지 삽입("{모델명}(으)로 변경") → 이후 응답은 변경된 모델로 생성.

#### 5.5.4 세션 잔여 시간
- **위치**: 입력 영역 최하단. Clock 아이콘 + "세션 잔여: N일 N시간". 클릭 시 툴팁.

**경고 상태**(색상 의미):

| 잔여 시간 | 텍스트 색상 |
|-----------|------------|
| 24시간 이상 | muted-foreground(기본) |
| 24시간 미만 | 경고(주황 계열) |
| 1시간 미만 | destructive(빨강) |

- **툴팁**(클릭 시): 세션 생성일 / 만료 예정일 / 잔여 시간(N일 N시간 N분). 정확한 색은 디자인 토큰 기준.

## 6. 응답 처리

### 6.1 스트리밍 효과 (Streaming Effect)

| 항목 | 정의 |
|------|------|
| 문자 출력 간격 | **12ms** (setInterval) |
| 출력 방식 | 라인 단위 프로그레시브 디스플레이(line-by-line) |
| 커서 애니메이션 | 커서 깜빡임(opacity 1 → 0 반복) |
| 상태 관리 | `streamingIndex`(현재 출력 위치), `streamingDisplayText`(화면 표시 텍스트) |
| 자동 스크롤 | 스트리밍 중 부드러운 자동 스크롤 지속 |
| 완료 처리 | 전체 출력 완료 시 커서 제거 + streamingIndex 리셋 |

**로딩 상태**(스트리밍 시작 전):
- 로딩 메시지는 약 **0.8초 간격**으로 순환(내용은 SpinX에서 내려줌). 텍스트는 muted-foreground + pulse, 점 인디케이터(순차 bounce).

### 6.2 응답 중지
- **조건**: 로딩 중일 때만 가능.
- **동작**: 전송 버튼(ArrowUp)이 중지 버튼(Square, destructive 배경)으로 전환 → 클릭 시 타이머/로딩 인터벌 정리 → 대화에 에러 메시지 삽입: "답변 생성이 중단되었습니다." → 재시도 가능.

### 6.3 에러 처리 및 재시도

| 항목 | 정의 |
|------|------|
| 최대 재시도 횟수 | 동일 질문당 **1회** |
| 재시도 버튼 | RefreshCw + "다시 시도"(ghost) |
| 재시도 소진 시 | 버튼 비활성화(흐리게 + not-allowed) |
| 재시도 카운트 기준 | 원본 질문 텍스트 기준(`Map<string, number>`) |

### 6.4 응답 복사
- **트리거**: AI 응답 메시지 호버 시 복사 버튼 표시.
- **동작**: Copy 클릭 → 클립보드 복사 → Check로 변경(약 2초 후 복귀).
- **복사 대상**: 텍스트 응답=원문, 차트 응답=차트 제목 + 설명, 에러 응답=에러 메시지.

## 8. 인터랙션 플로우

### 8.1 최초 오픈 (세션 없음)
```
1. SpinX 버튼 클릭
2. 패널 슬라이드 인
3. SpinX API에 세션 생성 요청 (scenarioId + userId)
4. 세션 ID 발급 → localStorage 저장
5. 현재 시나리오 데이터 기반 컨텍스트 요약 생성
6. 추천 질문 4개 생성
7. 패널에 요약 + 추천 질문 표시
```

### 8.2 재방문 (세션 있음, 14일 이내)
```
1. SpinX 버튼 클릭 → 패널 슬라이드 인
2. localStorage에서 세션 ID 확인
3. SpinX API에 세션 복원 요청
4. 이전 대화 이력 로드
5. 컨텍스트 요약 + 이전 대화 + 추천 질문 표시
6. 잔여 시간 업데이트
```

### 8.3 세션 만료 후 오픈
```
1. SpinX 버튼 클릭 → 패널 슬라이드 인
2. localStorage에서 세션 ID 확인
3. SpinX API에 세션 복원 요청 → 만료 응답
4. localStorage에서 만료 세션 ID 제거
5. 새 세션 생성 (8.1 플로우)
```

### 8.4 질문 → 응답
```
1. 사용자 메시지 입력 (또는 추천 질문 클릭)
2. 사용자 메시지 스레드에 추가
3. 로딩 상태 시작 (순차 메시지, 약 0.8초 간격)
4. SpinX API에 질문 전송 (세션 ID + 메시지 + 첨부)
5-a. 응답 수신 → AI 메시지 스레드에 추가
5-b. 사용자 중지 → "답변 생성이 중단되었습니다." 에러 메시지 삽입
5-c. 에러 발생 → 에러 메시지 + 재시도 버튼 (1회 제한)
6. 자동 스크롤
```

### 8.5 비교 결과 삭제 시
```
1. 시나리오 비교 결과 삭제 실행
2. 해당 비교에 연결된 SpinX 세션 만료 처리
3. localStorage에서 세션 ID 제거
4. (패널이 열려있었다면) 패널 자동 닫힘
```

## 9. 공통 사항

- **다크모드**: 모든 색상은 CSS 변수(디자인 토큰) 사용. 패널·메시지 영역 배경 테마 대응. 차트 색은 다크모드 분기(isDarkMode prop).
- **반응형**: 패널은 고정폭. 메시지 영역 세로 스크롤. 차트 응답은 ResponsiveContainer 폭 100%.
- **접근성**: 버튼은 키보드 접근 가능. textarea는 Enter/Shift+Enter 인터랙션. 외부 클릭 시 각주 팝오버 닫기. title 속성 제공(초기화 "대화 초기화", 복사 "복사").

이 화면(SpinX 패널)에서 직접 조작·발생하는 개선만 다룬다. 프롬프팅·MCP 기능 확장은 `SpinX_MCP_사용_정책서_v0.1.md`에서 다룬다.
