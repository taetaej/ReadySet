# 시나리오 결과 PDF 다운로드 정의서

## 문서 정보
- **작성일**: 2026-08-10
- **버전**: v1.0
- **적용 대상**: Ratio Finder 결과, Reach Predictor 결과, 시나리오 비교 결과
- **관련 컴포넌트**: `RatioFinderResult.tsx`, `ReachPredictorResult.tsx`, `ScenarioComparisonResult.tsx`

---

## 1. 개요

시나리오 결과 화면에서 현재 표시된 분석 결과를 PDF 파일로 다운로드하는 기능.
헤더 정보, 차트 시각화, 상세 데이터 테이블을 포함한 전체 리포트를 생성한다.

---

## 2. 적용 대상 화면

| 화면 | 컴포넌트 | URL |
|------|----------|-----|
| Ratio Finder 결과 | `RatioFinderResult.tsx` | `/reachcaster/scenario/ratio-finder/result` |
| Reach Predictor 결과 | `ReachPredictorResult.tsx` | `/reachcaster/scenario/reach-predictor/result` |
| 시나리오 비교 결과 | `ScenarioComparisonResult.tsx` | (비교 패널 내부) |

---

## 3. 트리거 (진입 방식)

### 3.1 개별 시나리오 결과 화면

결과 화면 상단 Export 드롭다운 메뉴 내 "PDF" 항목 클릭.

```
[Export ▾]
├── Copy Link
├── Excel
└── PDF        ← 이 항목
```

### 3.2 시나리오 비교 결과 화면

비교 결과 상단 Export 드롭다운 메뉴 내 "PDF" 항목 클릭.

## 4. PDF 파일 구성

### 4.1 Ratio Finder 결과 PDF

| 순서 | 섹션 | 포함 내용 |
|------|------|-----------|
| 1 | 커버 | 플랫폼 로고 + 시나리오명 + 생성일시 |
| 2 | 시나리오 정보 | 시나리오명, 모듈 타입, 브랜드, 업종, 기간, 타겟 GRP, 총 예산, 시뮬레이션 단위 |
| 3 | 최적 배분 요약 | Optimal Point 정보 (Digital:TVC 비율, 최대 도달률) |
| 4 | 리치커브 차트 | 예산 배분 비율별 도달률 그래프 (Optimal Point 마커 포함) |
| 5 | 시뮬레이션 상세 테이블 | 전체 배분 비율별 도달률 + 매체/상품별 예산 세분화 |
| 6 | 매체/상품 설정 정보 | 선택된 매체 목록, 상품별 예산 비중 |

### 4.2 Reach Predictor 결과 PDF

| 순서 | 섹션 | 포함 내용 |
|------|------|-----------|
| 1 | 커버 | 플랫폼 로고 + 시나리오명 + 생성일시 |
| 2 | 시나리오 정보 | 시나리오명, 모듈 타입, 브랜드, 업종, 기간, 타겟 GRP |
| 3 | 스코어카드 | 통합 도달률, 매체별 도달률, 매체별 기여도 |
| 4 | 리치커브 차트 | 예산 구간별 도달률 그래프 |
| 5 | 상세 데이터 테이블 | 매체/상품별 예산, 노출, CPM, 도달률 |
| 6 | 매체/상품 설정 정보 | 선택된 매체 목록, 개별 기간/타겟팅 설정 |

### 4.3 시나리오 비교 결과 PDF

| 순서 | 섹션 | 포함 내용 |
|------|------|-----------|
| 1 | 커버 | 플랫폼 로고 + "시나리오 비교 리포트" + 생성일시 |
| 2 | 비교 대상 요약 | 비교 시나리오 목록 (이름, 모듈, 브랜드, 기간) + 조건 차이 하이라이트 |
| 3 | Reach & CPRP 차트 | 시나리오별 도달률 + CPRP 비교 |
| 4 | 성과 콤보 차트 | 시나리오별 주요 성과 지표 |
| 5 | 채널별 예산 배분 | StackedBar 차트 |
| 6 | 통합 리치커브 | Unified Reach Curve (시나리오 오버레이) |
| 7 | 예산 요약 테이블 | Budget Summary + Efficiency Peak |

## 5. PDF 레이아웃 및 스타일

### 5.1 페이지 설정

| 항목 | 값 |
|------|-----|
| 용지 | A4 (210mm × 297mm) |
| 방향 | 세로 (Portrait) |
| 여백 | 상하 20mm, 좌우 15mm |
| 폰트 | Paperlogy (본문 Regular, 제목 Bold) |

### 5.2 커버 페이지

```
┌─────────────────────────────────────┐
│                                     │
│         [ReadySet 로고]              │
│                                     │
│                                     │
│      시나리오 결과 리포트             │
│      ─────────────────              │
│      {시나리오명}                     │
│                                     │
│      모듈: Ratio Finder             │
│      브랜드: {브랜드명}              │
│      생성일: 2026-08-10             │
│                                     │
│                                     │
│                                     │
│         ReadySet Platform           │
│                                     │
└─────────────────────────────────────┘
```

### 5.3 본문 스타일

| 요소 | 스타일 |
|------|--------|
| 섹션 타이틀 | 16px, Bold, foreground |
| 본문 텍스트 | 11px, Regular, muted-foreground |
| 테이블 헤더 | 10px, Bold, 배경 muted |
| 테이블 본문 | 10px, Regular |
| 차트 | 화면 렌더링 그대로 캡처, 페이지 폭에 맞춤 |
| 페이지 번호 | 하단 중앙, 10px |

### 5.4 다크/라이트 모드 대응

- PDF는 항상 **라이트 모드 스타일**로 출력
- 차트 캡처 시 라이트 모드 색상 기준 적용

## 6. 파일명 규칙

| 화면 | 파일명 형식 |
|------|-------------|
| Ratio Finder | `RF_{시나리오명}_{YYYYMMDD}.pdf` |
| Reach Predictor | `RP_{시나리오명}_{YYYYMMDD}.pdf` |
| 비교 결과 | `Comparison_{시나리오1}_{시나리오2}_{YYYYMMDD}.pdf` |

- 시나리오명에 특수문자 포함 시 `_`로 치환
- 파일명 최대 100자 (초과 시 시나리오명 말줄임)

## 7. 사용자 플로우

### 7.1 정상 플로우

```
1. Export 드롭다운 클릭
2. "PDF" 항목 클릭
3. 생성 중 상태 표시 (버튼 비활성 + 로딩 인디케이터)
4. 생성 완료 → 자동 다운로드 시작
5. 완료 토스트: "PDF 다운로드가 완료되었습니다."
```

### 7.2 생성 중 상태

| 상태 | UI |
|------|-----|
| 생성 중 | Export 버튼 영역에 스피너 + "PDF 생성 중..." 텍스트 |
| 완료 | 토스트 알림 (success) |
| 실패 | 토스트 알림 (error): "PDF 생성에 실패했습니다. 다시 시도해 주세요." |

### 7.3 예상 소요 시간

| 케이스 | 예상 시간 |
|--------|-----------|
| 개별 결과 (차트 1~2개 + 테이블) | 2~5초 |
| 비교 결과 (차트 5개 + 테이블) | 5~10초 |

## 9. 제약 사항 및 예외

| 상황 | 동작 |
|------|------|
| 시나리오 상태가 Processing/Error | Export 버튼 비활성 (Completed만 가능) |
| 차트 렌더링 실패 | 해당 섹션 "차트를 불러올 수 없습니다" 텍스트로 대체 |
| 매우 긴 테이블 (100행+) | 페이지 자동 분리 (page break) |
| 비교 시나리오 5개+ | 차트/테이블이 여러 페이지에 걸쳐 출력 |

---

## 10. 구현 방식 (개발 협의 필요)

PDF 생성 방식은 개발팀과 협의하여 결정한다.

| 옵션 | 장점 | 단점 |
|------|------|------|
| 프론트엔드 (html2canvas + jsPDF) | 서버 의존 없음, 빠른 적용 | 대용량 시 성능 이슈, 폰트 임베딩 복잡 |
| 백엔드 API (Puppeteer, wkhtmltopdf 등) | 안정적 품질, 서버 리소스 활용 | API 개발 필요, 네트워크 의존 |
| 하이브리드 (프론트 데이터 수집 → 백엔드 렌더링) | 유연한 구조 | 양쪽 개발 필요 |
