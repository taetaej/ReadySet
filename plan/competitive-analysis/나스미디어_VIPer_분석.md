## 3. ReadySet Budget Optimizer vs VIPer 비교

| 비교 축 | ReadySet Budget Optimizer | VIPer (나스미디어) |
|---|---|---|
| **모델 기반** | 업종별 벤치마크 모델 (22개 업종) | 광고주별 자사 데이터 모델 |
| **모델 엔진** | Google Meridian | Google Meridian + Meta Robyn |
| **데이터 소스** | BRIDGE 원천 (업종 통합 데이터) | 광고주 개별 집행 데이터 |
| **도입 속도** | 즉시 활용 (업종 선택만으로 분석 시작) | 데이터 수집/학습 기간 소요 |
| **정확도 특성** | 업종 평균 기반 → 범용적 정확도 | 광고주 특화 → 해당 브랜드 정확도 높음 |
| **운영사 성격** | CJ 메조미디어 (렙사, 통합 마케팅) | kt 나스미디어 (렙사, 디지털 마케팅 플랫폼) |
| **연계 솔루션** | Reach Caster (도달 예측) 연결 | 미확인 |
| **AI 인사이트** | SpinX 기반 결과 해석 | 미확인 |
| **외생변수** | 적용 (Meridian 기본 기능) | 적용 가능 (Meridian/Robyn 모두 지원) |

## 4. 포지셔닝 차이 분석

### 4.1 VIPer의 강점 (우리의 약점이 될 수 있는 부분)

| # | 강점 | 시사점 |
|---|---|---|
| 1 | 광고주 자사 데이터 기반 → 해당 브랜드에 특화된 정밀 모델 | "우리 브랜드만의 최적화"라는 메시지가 강력함 |
| 2 | Meridian + Robyn 듀얼 모델 제공 → 모델 간 결과 비교 가능 | 모델 선택권/검증 관점에서 신뢰도 어필 가능 |
| 3 | KT그룹 데이터 자산 활용 가능성 (통신 데이터, IPTV 등) | 데이터 레이어 확장 잠재력 |

### 4.2 VIPer의 약점 (우리의 기회)

| # | 약점 | 우리의 기회 |
|---|---|---|
| 1 | 광고주별 데이터 수집/학습 필요 → 도입 허들 높음 | **즉시 활용형**: 업종 선택만으로 바로 분석 시작 |
| 2 | 신규 광고주/데이터 부족 브랜드는 활용 불가 | **범용성**: 데이터 없는 브랜드도 업종 벤치마크로 커버 |
| 3 | 단독 MMM 솔루션 (도달 예측 연계 미확인) | **End-to-End**: Budget Optimizer → Reach Caster 연속 분석 |
| 4 | 렙사가 아닌 플랫폼 컴퍼니 포지션 (미디어 바잉 연계?) | **렙사 실무 밀착**: 실제 미디어 플래닝 워크플로우에 통합 |

### 4.3 경쟁 구도 정리

```
┌─────────────────────────────────────────────────────────┐
│                    MMM 기반 예산 최적화                    │
├─────────────────────────┬───────────────────────────────┤
│  광고주 데이터 기반       │  업종 벤치마크 기반            │
│  (Custom Model)         │  (Industry Model)             │
├─────────────────────────┼───────────────────────────────┤
│  VIPer (나스미디어)       │  Budget Optimizer (ReadySet)  │
│  - 정밀도 높음           │  - 즉시 활용 가능              │
│  - 도입 허들 높음         │  - 도입 허들 낮음             │
│  - 데이터 필요           │  - 데이터 불필요              │
│  - Meridian + Robyn     │  - Meridian + 외생변수        │
└─────────────────────────┴───────────────────────────────┘
```

## 5. 전략적 시사점

### 5.1 우리의 포지셔닝 강화 방향

1. **"Zero Data Start"** — 광고주 데이터 없이도 즉시 분석 가능한 진입 장벽 없는 솔루션
2. **"업종 인텔리전스"** — 렙사로서 축적한 업종별 시장 패턴 내재화 (개별 브랜드가 볼 수 없는 업종 전체 맥락)
3. **"End-to-End 미디어 플래닝"** — 예산 배분 → 도달 예측을 하나의 플로우로 연결 (VIPer에는 없는 구조)
4. **"SpinX 인사이트"** — AI 기반 결과 해석으로 비전문가도 즉시 이해 가능

### 5.2 방어 논리 (VIPer 대비 약점 보완 메시지)

| 예상 공격 포인트 | 방어 메시지 |
|---|---|
| "광고주 자사 데이터 기반이 더 정확하지 않나?" | 업종 모델은 개별 브랜드가 확보하기 어려운 시장 전체 패턴을 반영함. 또한 데이터 부족 상황에서도 안정적 예측 가능 |
| "Robyn도 제공하는데?" | Meridian은 Google의 최신 Bayesian MMM으로 불확실성 정량화 가능. 단일 모델에 집중하여 정확도와 안정성 확보 |
| "커스텀 모델이 더 맞춤형 아닌가?" | 즉시 활용 가능 + Reach Caster 연계라는 실무 가치가 학습 대기 시간 대비 ROI가 높음 |
